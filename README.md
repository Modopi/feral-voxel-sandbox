# FERAL 0.4.0 — 개척 원정 프로토타입

Android에서 오프라인으로 탐험·채굴·전투·수집·제작을 연결하는 1인칭 복셀 샌드박스 프로토타입.

## 0.4.0: 탐험·제작·공동체·수호자를 연결하는 개척 원정

**개발 브랜치의 미배포 프로토타입.** 월드 선택 → **개척 원정**으로 시작합니다. 이미 월드 목록이 있다면 새 월드 유형에서 개척 원정을 선택하세요. 기존 섬·기계 시험장은 별도 저장으로 유지됩니다.

- 시드 기반 지역 이동과 지형·생태·전리품 보존, 목표 방향과 보급로.
- 체력·포만·회복·경험, 무기·갑옷·연구, 유적 탐사와 3단계 수호자.
- 마을 생산·소비·재고, 교역·지원·동맹·약탈·화해·집단 중재.
- 탐험 자원으로 제작한 차량의 부품 배치·손상·수리, 다중 포탑과 간이 회전익 비행.
- 전용 가방·제작 UI, 원정 장부, 모바일 HUD.

장부 **J**, 상호작용 **R**, 회복약 **H**. 모바일에서는 장부·상호작용 버튼을 사용합니다. 처음에는 마을에서 원목을 교역하고 가방에서 목재를 만들어 지원해 보세요. 보스 처치 없이도 탐험·지원·유적 보상으로 모든 기술 연구가 가능합니다.

게임 0.4.0 / 400, 최소 네이티브 0.3.1 / 301. 네이티브와 저장 스키마 번호는 유지합니다. 저장소는 현재 공개 상태지만 기존 앱 업데이트 연결은 여전히 토큰을 요구합니다.

지역 전환형 프로토타입이며 무중단 무한 월드·도시 AI·정밀 항공 역학은 후속 범위입니다. [플레이 방법·구현 범위·저장 한계](docs/FRONTIER-PROTOTYPE.md)를 확인하세요. 아래 0.3.x/0.2.x 설명은 이전 기본 섬·시험장 및 배포 이력입니다.

## 0.3.1: 앱은 고정하고 게임 버전 선택

`Feral-0.3.1-android.apk`를 기존 앱 위에 한 번 설치합니다. 이후 상단 **게임 버전**에서 GitHub에 배포된 게임을 선택·전환할 수 있습니다. 앱은 0.3.1로 유지됩니다. 수동 전환은 빌드별로 저장을 분리하며 첫 선택은 새 저장으로 시작합니다. 동봉 게임으로 돌아오면 기존 진행을 복원합니다.

개발 시 최신 main에서 `V_0.3.2` 또는 `V_vehicle` 같은 브랜치를 만들고 push합니다. Actions가 게임 자산을 서명·게시하면 앱의 목록에 새 빌드가 표시됩니다. main은 기존 stable 경로도 유지합니다. 구버전 선택 후에는 자동 stable 업데이트가 선택을 덮어쓰지 않습니다. 자세한 절차는 [docs/RELEASING.md](docs/RELEASING.md)를 참조하세요.

## 0.3.0: 움직이는 복셀 기계 — Vertical Slice 0.1

타이틀의 **내 월드 · 기본 맵 / 기계 베타 맵**에서 선택합니다. 기본 탐험 맵은 기존 저장을 그대로 읽고, 기계 베타 맵은 독립된 고정 시험장을 엽니다. 월드 이름·유형·섬 시드를 지정하여 여러 월드를 만들고 이름 변경·삭제할 수 있습니다. 삭제는 해당 월드만 대상으로 확인 창을 거칩니다. 월드 목록 메타데이터와 각 월드 저장은 별도 키로 보관하며, 기본 맵은 기존 `feral.world.v1`을 이동하거나 덮어쓰지 않습니다. 저장 실패 시 월드 목록 이동을 차단합니다.

기계 베타 맵에서는 7×3×7 격자에 0.5m 차체·모터·바퀴를 배치합니다. 원점 차체를 기준으로 6면 연결된 모터·바퀴가 작동하고, 지면층 좌우 바퀴가 접지·조향을 제공합니다. 경량·중량 예제는 시험 자원을 초기화합니다. 주행 시작 후 WASD/방향키 또는 터치 방향 버튼으로 운전하고 Space/제동 버튼으로 감속합니다. 정지·조립으로 전환하여 격자 도구의 타격 시험·수리·제거를 사용합니다. 모터 HP는 출력, 바퀴 HP는 접지·조향에 반영됩니다. 장애물 충돌도 국소 HP를 감소시킵니다. 초록 광맥 (−6, 9) 근처에서 정지 후 채굴하면 조립·수리 재료를 얻습니다.

설계도와 부품별 HP·역학 상태를 분리했습니다. `machine/model.js`는 DOM/Three.js와 독립된 순수 모델, `machine/view.js`는 표현·입력 어댑터입니다. 책임·명령 흐름은 [docs/MACHINE-ARCHITECTURE.md](docs/MACHINE-ARCHITECTURE.md)에 기록했습니다. 기계 시험장은 60Hz 평면 간이 역학이며 3D 강체·서스펜션·전복·분리 파편·무장을 구현하지 않습니다. 기존 섬의 채굴 자원을 공유하지 않습니다. 15초마다 저장하며 목록으로 나가기·앱 비활성화 시에도 저장합니다.

```bash
node tests/machine-check.cjs
```

0.3.0 APK: `build/Feral-0.3.0-android.apk`. 게임 변경만 포함하므로 최소 네이티브는 205를 유지합니다. 앱 자체는 stable 배포 체계이며 **기계 맵이 베타 기능**입니다. 새 베타 채널을 추가한 버전은 아닙니다.

## 0.2.5: 버전 배포와 자동 업데이트

0.2.5 APK부터 비공개 GitHub의 서명된 게임 업데이트를 받습니다. 메뉴 → 업데이트 → GitHub 연결에서 저장소 한정 **Contents: Read-only** fine-grained 토큰을 한 번 등록하세요. 토큰은 Android Keystore로 암호화하며 게임 코드에 노출하지 않습니다. 연결 없이도 오프라인 플레이가 가능합니다.

새 버전은 실행할 때 확인·다운로드하고 다음 실행에 적용합니다. **저장 후 적용**으로 즉시 재시작할 수 있습니다. 서명·파일 해시·경로·크기를 검증하고, 시작 성공 전 실패하면 이전 게임과 저장으로 복구합니다. 네이티브 기능 변경은 새 APK 설치가 필요합니다.

버전의 기준은 `version.json`입니다. `node tools/version.mjs`로 관련 파일을 맞추고 CHANGELOG를 갱신한 뒤 검증된 변경을 main에 반영하면 GitHub Actions가 버전별 Release와 업데이트 채널을 배포합니다. 절차와 복구 범위는 [docs/RELEASING.md](docs/RELEASING.md), 개발 규칙은 [AGENTS.md](AGENTS.md)에 기록했습니다.

## 0.2 변경

- 발 충돌의 5cm 침투 여유를 제거하고, 60Hz 고정 물리·충돌면 스윕·렌더 보간으로 교체했습니다. 멈춰 있을 때 중력과 위쪽 보정이 반복되는 현상을 고쳤습니다.
- 캐릭터 몸 높이 1.50m, 눈높이 1.36m, 반경 0.23m입니다. 보행 속도 3.2m/s, 달리기 4.8m/s이며, 0.5m 계단을 자동으로 오르고 1m 턱은 점프합니다.
- 몹의 신체를 더 작은 0.25m/0.125m 복셀 구성으로 다시 설계했습니다. 화면 속 도구가 차지하는 면적을 줄이고 기본 시야각을 82도로 넓혔습니다. 출발 지점을 더 열고 강변에 0.5m 계단길을 추가했습니다.
- 기본 생태 개체는 168마리이며 3,000개체 실험 모드는 유지합니다. 화면 뒤 개체의 렌더 제출을 줄이고 생명 이동도 보간합니다.
- 지형은 1m 기준을 유지하면서 수정한 칸만 8개의 0.5m 셀로 나눕니다. 표시·조준·충돌·채굴·설치·저장이 같은 반 칸 데이터를 사용합니다.
- 가방, 제작, 채굴 자원 드롭, 몹의 생체 복셀/전리품 드롭, 자동 수집, 재료를 사용하는 건축과 식생 복원을 추가했습니다.

## 설치와 업데이트

`Feral-0.2.5-android.apk`를 Android 기기에서 열어 설치합니다. Android 8.0 이상과 WebGL 2를 지원하는 최신 Android System WebView가 필요합니다. 0.1과 같은 applicationId와 시험 서명 키를 사용하며 versionCode를 205로 올렸습니다. 기존 앱을 지우지 않고 업데이트 설치하면 저장을 유지할 수 있습니다.

0.1 저장도 이어서 읽습니다. 기존 지형 수정·개체·분리된 신체 상태를 유지하고 가방에 시작 재료를 지급합니다. 축소된 몹에서 기존 부위의 손상 복셀 수가 달라지면 남은 비율에 맞춰 옮깁니다. 앱 데이터 삭제·앱 제거 시 저장은 삭제됩니다.

게임 자산을 APK에 포함합니다. 0.2.5부터 업데이트 통신을 위한 인터넷 권한만 추가했으며 저장소·위치 권한은 요청하지 않습니다. 토큰 연결 후 업데이트가 가능하고, 연결하지 않아도 현재 버전을 실행할 수 있습니다.

## 조작과 자원 흐름

| 행동 | 모바일 | 키보드 |
| --- | --- | --- |
| 이동·시점 | 왼쪽 스틱·오른쪽 드래그 | WASD·마우스 |
| 점프·비행 | ↑·◇ | Space·F |
| 도구 선택·사용 | 아래 도구·오른쪽 사용 | 1~9·마우스 클릭 |
| 가방·제작 | 우측 상단 ▦ | I / Tab |
| 채굴·건축 크기 변경 | 화면의 범위 버튼 | B |
| 비행 높이 | 위아래를 보며 이동·↑ 상승 | Q 하강·E 상승 |

처음에는 1m 곡괭이가 선택되어 있습니다. 블록을 채굴하면 바닥에 자원이 떨어집니다. 드롭에서 약 1.5m 이내로 접근하면 가방에 자동으로 들어갑니다. 생명에 펄스를 사용하면 떨어진 복셀을 같은 방식으로 수집합니다. 몹이 죽으면 생명 정수나 결정 등의 전리품도 생성됩니다.

가방의 재료를 누르면 건축 재료로 선택됩니다. 흙·돌·원목·목재·모래는 0.5m 조각 단위입니다. 1m 블록을 설치하면 조각 8개, 0.5m 블록은 1개를 소비합니다. 캐릭터와 겹치거나 이미 채워진 공간에는 설치되지 않습니다. 씨앗 도구도 씨앗 1개를 소비합니다. 물·산과 개체 생성 도구는 실험용으로 계속 제공합니다.

| 채굴 도구 | 한 번의 범위 | 최대 부피 | 획득 |
| --- | --- | --- | --- |
| 정밀 끌 | 0.5 × 0.5 × 0.5m | 0.125m³ | 기본 장비 |
| 곡괭이 | 1 × 1 × 1m | 1m³ | 기본 장비 |
| 해머 | 2 × 2 × 2m | 8m³ | 돌 12 + 목재 4 + 생체 수지 2 |

목재는 원목 2개로 4개를 제작합니다. 생체 수지는 생체 복셀 6개로 2개를 만듭니다. 결정·수지·생명 정수를 모으면 강화 펄스도 제작할 수 있습니다. 재료가 모자라면 제작 버튼이 비활성화되며, 제작과 소비는 한 번에 처리합니다.

30초마다 자동 저장하며 메뉴의 **지금 저장**도 사용할 수 있습니다. 지형·반 칸 수정·가방·제작 장비·바닥 드롭·생태·플레이어 상태를 저장합니다.

## 세계와 시뮬레이션

- 시드 기반 160 × 160 × 40m의 유한한 섬, 강·숲·화산 지형·폐허와 5개 발견 장소.
- 이끼사슴·구리여우·청금딱정: 섭식·회피·포식·에너지·번식·죽음·토양 영양분·식생 회복.
- 복셀 제거, 연결 성분 분리, 부모 부위 손실 전파, 남은 다리에 따른 이동 속도 변화.
- 셀 유체의 중력·수평 이동과 물/산 혼합, 연소·소화·부식, 물과 용암의 현무암/수증기 반응.

물과 산은 여전히 1m 셀에서 계산합니다. 0.5m 틈을 정밀하게 통과하는 유체는 아직 지원하지 않습니다. 반응은 규칙 모델이며 실제 pH·분자 화학·압력/점성 유체 역학을 풀지 않습니다. 관절은 절차적 애니메이션과 파괴 가능한 부모 관계이며 완전한 강체 래그돌은 아닙니다. 무한 월드·멀티플레이·체력/허기 기반 생존 모드는 없습니다.

## 성능 구조와 한계

지형은 16 × 40 × 16 청크의 그리디 표면 병합을 사용합니다. 반 칸 데이터는 수정한 곳에만 할당하고 변경 청크만 재생성합니다. 가까운 개체부터 상세 복셀을 배정하며 먼 개체는 부위 단위 인스턴싱을 사용합니다. 생태 판단 주기는 거리별 0.25/1/3초이고, 유체와 반응에도 셀 예산을 둡니다.

개체 상한은 3,200마리, 드롭은 최대 600묶음입니다. 같은 종류의 가까운 드롭은 합쳐지며 240초 뒤 사라집니다. 가방은 자원 종류별 최대 9,999개입니다. 수천 개체가 모두 상세 복셀/전체 물리로 동시에 처리되는 구조는 아닙니다. 매우 낮은 프레임에서는 과도한 따라잡기 계산을 막기 위해 시뮬레이션 시간이 느려질 수 있습니다.

3,000개체에서 특정 FPS를 보장하지 않습니다. 휴대폰 실기기의 업데이트 설치·발열·배터리·장시간 플레이는 별도 검증이 필요합니다.

Java 17 JDK, Python 3, Android SDK Platform 35와 Build Tools 35.0.0이 필요합니다.

```bash
export ANDROID_HOME=/absolute/path/to/Android/sdk
bash build-apk.sh
```

결과는 `build/Feral-0.2.5-android.apk`입니다. 제공한 Gradle 프로젝트도 사용할 수 있습니다(Gradle 8.9 / AGP 8.7.3). `signing/prototype.keystore`는 재빌드용 공유 시험 키이며 배포용 서명은 별도로 관리해야 합니다.

웹에서 실행하려면 다음 서버를 시작하고 `http://localhost:8080`을 엽니다. APK에는 서버가 필요 없습니다.

```bash
python3 -m http.server 8080 --directory app/src/main/assets
node --test tests/*.test.js
```

브라우저 검증은 개발용 Playwright와 Chromium이 필요합니다.

```bash
FERAL_CHROME=/absolute/path/to/chrome node tests/browser-check.cjs
FERAL_CHROME=/absolute/path/to/chrome node tests/progression-check.cjs
FERAL_CHROME=/absolute/path/to/chrome node tests/updates-ui-check.cjs
```
