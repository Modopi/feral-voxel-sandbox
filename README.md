# FERAL 0.1 — 살아 있는 복셀

안드로이드에서 오프라인으로 탐험하고 생태·복셀 파괴·유체 반응을 시험하는 1인칭 샌드박스 프로토타입.

## 설치와 첫 플레이

1. `Feral-0.1-android.apk`를 Android 기기에서 열어 설치합니다. Android 8.0 이상과 WebGL 2를 지원하는 최신 Android System WebView가 필요합니다.
2. FERAL을 실행한 뒤 **탐험 시작**을 누릅니다. 가로 화면으로 실행됩니다.
3. 왼쪽 스틱으로 이동하고, 오른쪽 빈 화면을 드래그해 둘러봅니다. 아래 도구를 선택하고 오른쪽 **사용** 버튼을 누릅니다.
4. **메뉴 → 생태계 → 3,000 개체 실험**으로 부하를 시험할 수 있습니다. FPS가 낮으면 **환경 설정 → 절전**을 선택합니다.
5. 30초마다 자동 저장됩니다. **지금 저장**을 누를 수도 있습니다. 다시 실행하면 **이전 탐험 이어하기**로 돌아옵니다. 앱 데이터 삭제·앱 제거 시 저장도 삭제됩니다.

외부 서버·로그인·다운로드가 없으며, 인터넷·저장소·위치 등의 권한을 요청하지 않습니다. 업데이트 설치는 동봉한 시험용 서명 키를 계속 사용해야 기존 앱과 저장을 유지할 수 있습니다.

## 포함한 기능

| 항목 | 구현 |
| --- | --- |
| 탐험 | 시드 기반 160 × 160 × 40 m 섬, 강·숲·화산 지형·폐허, 5개 발견 장소, 미니맵 |
| FPS 조작 | 멀티터치 이동·시점·점프·비행, 마우스와 WASD 지원, 시야각·감도·왼손 설정 |
| 지형 | 1 m 정육면체, 채굴·흙 블록 설치, 나무와 잎을 포함한 개별 블록 편집 |
| 생명 | 이끼사슴·구리여우·청금딱정, 0.25 m / 0.125 m 신체 복셀 |
| 손상 | 복셀 제거, 연결 성분 판정, 신체 분리와 조각, 부모 부위 손실 전파, 남은 다리에 따른 속도 변화 |
| 생태 | 풀 섭식·위협 회피·포식·에너지·번식·죽음·토양 영양분·식생 회복 |
| 유체 | 셀 사이의 중력·수평 이동, 셀 간 물량과 용질량 보존, 물과 산 혼합 |
| 반응 | 연소·확산·소화·유기물 부식·물과 용암의 현무암/수증기 생성 |

도구는 관찰 렌즈 / 복셀 펄스 / 지형 절삭기 / 흙 블록 / 물 / 불 / 산 / 생태 복원 / 개체 생성입니다. 물과 산 도구는 샌드박스 방식으로 물질을 추가하며, 게임 내 재료 보유량 제한은 없습니다.

## 현재 범위와 한계

이 버전은 요구한 시스템을 연결해 플레이할 수 있게 만든 초기 프로토타입입니다. 무한 월드, 멀티플레이, 제작·인벤토리, 완전한 생존 모드는 없습니다. 생태계는 규칙 기반이며 장기간 개체 수의 안정성을 보장하지 않습니다. 일반적인 분자 화학, 압력·유속·점성을 푸는 유체 역학, 관절 강체를 푸는 래그돌은 구현하지 않았습니다. 관절은 절차적 애니메이션과 파괴 가능한 부모 관계로 표현합니다.

물은 셀별 최대 1 m³이며 중력·평형에 따라 단계적으로 이동합니다. 계산량을 제한하므로 한 번에 전체 물 셀을 갱신하지 않습니다. 반응으로 소비된 물은 수증기 통계로 반영하지만 수증기의 기체 이동은 계산하지 않습니다. 산의 양은 반응 시 소비됩니다. 0.00005 m³ 미만의 잔여 셀은 제거하는 수치 오차 한계가 있습니다. 산도 표시는 모델 내 용질 비율이며 실제 pH가 아닙니다.

수천 개체가 모두 상세 복셀과 전체 물리로 동시에 계산되는 구조는 아닙니다. 모든 개체의 이동·상태를 유지하면서 판단 주기와 표시 상세도를 거리에 따라 나눕니다. 휴대폰 실기기 성능과 발열·배터리 사용은 아직 검증하지 않았으므로 3,000개체에서 특정 FPS를 보장하지 않습니다.

## 성능 구조

- 지형: 16 × 40 × 16 청크의 그리디 표면 병합. 변경한 청크와 경계만 다시 생성.
- 생명: 템플릿 복셀을 공유하고 손상한 부위에만 개체별 점유 배열 할당.
- 표시: 가까운 10 / 24 / 42개체에 상세 복셀 우선 배정. 나머지는 관절 부위 단위 인스턴싱. 화면 밖 청크는 프러스텀 컬링.
- 판단: 근거리 0.25초, 중거리 1초, 원거리 3초. 공간 해시로 인근 생물 탐색.
- 유체: 틱당 셀 예산을 제한하고 표시 갱신을 분산. 반응·식생도 별도 예산 적용.
- 한도: 생명 3,200개체, 일시 조각 350개, 월드 상한 160 × 160 × 40.
- 매우 낮은 프레임에서는 틱당 시간을 제한해 시뮬레이션이 실제 시간보다 느려집니다. HUD FPS는 실제 렌더 간격을 사용합니다.

## 파일 구조

```text
app/src/main/assets/world.js       지형·물·화학·식생
app/src/main/assets/entities.js    생태·복셀 신체·관절·손상
app/src/main/assets/render.js      청크 메시·인스턴싱·거리 상세도
app/src/main/assets/main.js        조작·FPS 루프·도구·저장·UI
app/src/main/assets/index.html     화면
app/src/main/assets/style.css      터치 HUD·메뉴
app/src/main/java/.../MainActivity.java  오프라인 Android 컨테이너
build-apk.sh                      SDK 도구 직접 빌드
verification/                     실제 실행 검증 결과
```

Three.js r170을 로컬에 포함했습니다. MIT 라이선스는 `assets/vendor/THREE-LICENSE.txt`에 있습니다. 추가 네트워크 자산은 사용하지 않습니다. Android 컨테이너는 앱에 포함한 자산만 HTTPS 가상 출처로 제공하며 외부 페이지 이동과 일반 파일 접근을 차단합니다.

## 다시 빌드

Java 17 JDK, Python 3, Android SDK Platform 35와 Build Tools 35.0.0을 설치합니다.

```bash
export ANDROID_HOME=/absolute/path/to/Android/sdk
bash build-apk.sh
```

결과: `build/Feral-0.1-android.apk`. Gradle을 설치했다면 제공한 Gradle 프로젝트로 `gradle :app:assembleDebug`를 실행할 수도 있습니다(Gradle 8.9 / Android Gradle Plugin 8.7.3).

`signing/prototype.keystore`는 이 시험 앱의 재빌드를 위한 공유 시험 키입니다. 암호와 별칭은 빌드 스크립트에 있습니다. 공개 배포용으로는 별도 서명을 사용해야 합니다.

## 웹에서 실행

```bash
python3 -m http.server 8080 --directory app/src/main/assets
```

같은 컴퓨터에서 `http://localhost:8080`을 엽니다. ES 모듈이므로 HTML을 파일 탐색기에서 직접 여는 대신 HTTP 서버를 사용하세요. Android APK는 서버 실행 없이 동작합니다.

## 검증 실행

```bash
node --test tests/simulation.test.js
```

브라우저 검증 스크립트는 개발용 Playwright와 Chromium이 필요합니다. `FERAL_CHROME=/absolute/path/to/chrome node tests/browser-check.cjs`로 실행합니다. 기본 경로는 이 제작 환경의 도구 경로이므로 다른 환경에서는 지정해야 합니다. 테스트는 파일 자산을 읽기 위해 개발용 `--allow-file-access-from-files` 플래그를 사용합니다. 실제 APK는 해당 플래그를 사용하지 않습니다.

모바일 실기기에 설치·실행하는 최종 검증은 별도로 필요합니다. 검증한 범위와 수치는 `verification/VALIDATION.md`를 참고하세요.
