## 0.13.0 — 하나의 게임 화면 (통합 1단계)

FERAL을 맵마다 다른 게임이 아닌 하나의 게임으로 합치기 시작했습니다. 이제 기본 섬·개척 원정·콘텐츠 탐험이 같은 화면을 씁니다. 콘텐츠 탐험에서도 기존 핫바, 36칸 가방(제작·제작 대기열), 체력·포만 HUD, 지도·상태·상호작용 버튼, 원정 장부 창(여정·상태·연구·무기·설비·기계·공동체·던전 장치·신앙), 일시정지 메뉴, 환경 설정, UI 배치 편집기를 그대로 사용합니다. 조작·알림·설정 코드도 모든 맵이 공유합니다. 기계 시험장과 규칙·데이터의 통합, 기존 맵을 같은 시스템의 맵으로 옮기는 작업은 다음 단계입니다. [통합 기준과 단계](docs/UNIFIED-GAME.md) · [0.13.0 검증 기록](verification/0.13.0.md)

## 0.12.1 — Android 콘텐츠 탐험 로딩 수정

0.11.0과 0.12.0의 콘텐츠 탐험은 Android 앱에서 "숲과 오래된 건축물을 준비하고 있습니다." 화면에 멈췄습니다. 앱이 `.mjs` 파일을 JavaScript로 응답하지 않아 게임 모듈이 거부됐기 때문입니다. 0.12.1에서 모듈을 `.js`로 바꿔 게임 업데이트만으로 고쳤습니다. 로딩 화면에는 진행 막대·현재 단계·퍼센트·경과 시간이 표시되고, 오래 멈추거나 파일을 불러오지 못하면 안내와 다시 시도 버튼이 나옵니다. [0.12.1 검증 기록](verification/0.12.1.md)

## 0.12.0 — 구현된 기능의 화면 연결

코드에는 있었지만 화면에서 쓰거나 볼 수 없던 기능 28가지를 연결했습니다. [목록과 근거](docs/UI-REACHABILITY.md)

- **콘텐츠 탐험:** 터치 화면에 달리기와 기계 하강·제동 버튼을 추가했습니다. 가방에서 연구를 멈추거나 전환하고, 제작 대기열에서 진행률과 막힌 이유를 보며 먼저 진행·취소(재료 반환)·5개 제작을 할 수 있습니다. 도구 내구도도 보입니다.
- **전투와 던전:** 보스의 단계·부위 파손·기술 예고(방향 포함), 생명체의 공격 예고와 위험 구역을 경고합니다. 보스 전장 장치를 공격해 부술 수 있고, 회수하지 않은 보상 위치가 빛기둥으로 표시됩니다. 던전 장치의 세부 상태를 보고, 공급선을 분리하거나 부서진 구조 부품을 복구할 수 있습니다.
- **기존 월드:** 기본 섬에서 관찰 렌즈와 물·불·산·개체 생성 도구(메뉴 → 개발·생태)를 쓸 수 있습니다. 설정에서 미니맵과 주변 사건 알림을 켤 수 있고, 새 장소 발견을 알립니다.
- 실패 사유를 영어 코드 대신 한국어로 안내하고, 동시에 생긴 알림을 차례대로 보여 줍니다.

Chromium 터치 입력으로 위 경로를 검사했으며 실제 Android 기기 검증은 아직 남아 있습니다. [0.12.0 검증 기록](verification/0.12.0.md)

## 0.11.0 — 콘텐츠 탐험 통합

내 월드에서 **콘텐츠 탐험** 유형으로 새 월드를 만들면 무한 청크 지형, 설계된 생명체·던전·보스, 연구·제작과 실제 설치 설비·기계를 이용할 수 있습니다. 기존 월드 유형과 저장은 유지합니다. 가방·제작 화면에서 연구와 생산을 시작하고, 설치한 설비 근처에서 작업하거나 에너지 망을 연결합니다.

외피 공격도 전체 HP를 줄이며, 뼈대 파손은 해당 행동을 제한합니다. 내부 부위를 노리는 관통·충격 전달을 추가했고 기존 탐험 모드의 무기에도 적용합니다. 사망한 장소의 물품은 사라지지 않으며 10m 안에 돌아오면 요정이 회수를 돕습니다. 신앙·시련은 유적의 제단에서 선택할 수 있습니다.

키보드·터치 조작, 저장 복구, 준비된 상태의 보스 공략과 에너지 설비 연결을 검사했습니다. 모델의 고티어 비용 검사와 실제 장거리 플레이 완주는 구분합니다. Android 실기기의 프레임·메모리·발열·장시간 플레이·업데이트 설치는 아직 검증하지 않았으며 전체 목표 완료를 의미하지 않습니다. [0.11.0 검증 기록](verification/0.11.0.md)을 확인하세요.

새 복셀 에셋은 [제작 도구와 공통 규칙](docs/VOXEL-ASSET-RULES.md)을 통해 만듭니다. 같은 부위에 겹치는 추가는 즉시 거부하고, 교체·빈 공간 채우기·삭제는 명시적인 작업으로 수행합니다. 관절 부위는 보존하며 같은 엔티티 내부 충돌은 제외하고 외부 개체와 지형에는 충돌합니다.


## 0.10.0 — 구조와 물체가 남는 샌드박스

땅과 연결이 끊긴 복셀 덩어리를 독립 물체로 다루며, 잡고 끌기·밀기·던지기·고정·재료 부착·추가 절단을 지원합니다. 운반 집게를 제작해 무거운 물체를 옮기고, 낙하·충돌의 질량과 속도에 따른 피해를 지형·물체·차량·생물에 적용합니다. 동물과 인물형 훈련체는 외피와 내부 골격을 구분하며 골격 단절에 따라 행동이 달라집니다. 새 지역에는 해체·운반 작업장이 있습니다.

[구현 범위와 조작](docs/STRUCTURAL-SANDBOX.md), [0.10.0 검증 기록](verification/0.10.0.md). 일반 주민·플레이어의 전신 구조 손상과 전신 관절 래그돌, 실제 Android 장시간 성능 검증은 남아 있습니다.

## 첫 신호 — 콘텐츠 완주 가능한 베타 후보

**야영지에서 준비 → 탐험·전투·주민 협력 → 신호 복원 → 시설과 장비 성장 → 다음 지역**으로 이어지는 캠페인입니다. 출발지·동쪽·북쪽의 세 신호를 연결해 송신탑을 점화한 뒤 측량·보급·수호자 잔향 원정을 계속할 수 있습니다.

- 좌측 **여정**에서 현재 목표와 준비물을 확인합니다. 야영지에서는 텃밭·취사장·정비소를 건설하고 작물을 심고 수확합니다.
- 신호는 유적 탐사, 수호자 격파, 주민 의뢰와 동맹 중 원하는 경로로 복원합니다. 지역마다 다른 공격 예고를 보고 피할 수 있습니다.
- 제작 검색·제작 가능 필터·부족 재료와 획득처 안내를 사용합니다. 현재 아이템 47종·제작법 51개를 초기 지급품 없이 얻는 경로를 검사합니다.
- 지형 재질·그림자·하늘·주야 조명·수면과 주민/수호자/채집물 형태를 개선했습니다. 슬롯·버튼·아이콘은 청록색과 황동색으로 통일했습니다. 설정에서 그래픽 품질을 조절할 수 있습니다.
- 반 칸 채굴과 손상 보존, 실제 아이템 핫바, 월드 정보창 우선 표시, 누른 버튼 위 시점 드래그, 공기역학과 월드 조립을 유지합니다.

빈 가방에서 캠페인과 반복 원정의 완료 경로, 저장 복원, 실제 터치 좌표의 접근성을 자동 검증합니다. 실제 Android의 장시간 플레이·발열·성능·난도는 아직 검증하지 않았습니다. [설계와 사례 분석](docs/FIRST-SIGNAL.md), [검증 기록](verification/0.9.0.md).

0.9.1에서는 주인공·주민을 관절이 연결된 정밀 복셀 캐릭터로 바꾸고, 얼굴·의복·도구·동물의 종별 형태와 표면을 보강했습니다. 가방·상태창에서 실제 3D 개척자를 회전하고 동작을 볼 수 있습니다. [캐릭터 설계와 사례](docs/VOXEL-CHARACTERS.md), [0.9.1 검증](verification/0.9.1.md).

## 설치·업데이트

앱 0.3.3에서는 **메뉴 → 업데이트 → 지금 확인 → 저장 후 적용**으로 게임 0.13.0을 받습니다. 특정 버전에 고정했다면 **게임 버전 → 0.13.0**을 선택하세요. 버전 목록에 아직 없다면 공개 게시가 완료된 뒤 다시 확인합니다. 처음 설치하거나 앱 0.3.2 이하인 경우 [공개 릴리스](https://github.com/Modopi/feral-voxel-sandbox/releases/tag/v0.13.0)의 `Feral-0.3.3-android.apk`를 설치합니다. 기존 앱을 삭제할 필요가 없습니다.

게임 1201, 앱/최소 앱 303, 저장 스키마 2. 기존 저장을 읽으며 기존 지역의 지형을 다시 생성하지 않습니다. 수동 게임 버전 전환은 빌드별 저장을 분리하며 첫 선택은 새 저장으로 시작합니다. [배포·설치 안내](docs/RELEASING.md), [자원 순환 규칙](docs/PERSISTENT-WORLD-AND-LOOPS.md).


앱이 사용하는 공개 배포 경로는 동일 저장소의 `updates` 브랜치입니다: [버전 목록](https://raw.githubusercontent.com/Modopi/feral-voxel-sandbox/updates/catalog.json), [최신 게임 패키지](https://raw.githubusercontent.com/Modopi/feral-voxel-sandbox/updates/stable.feral). 0.13.0은 별도의 불변 패키지로 추가하며 0.12.1을 포함한 이전 패키지는 그대로 보존합니다. 콘텐츠 탐험을 Android 앱에서 하려면 0.12.1 이상을 사용하세요. 기존 저장에서 콘텐츠 탐험을 이용하려면 내 월드에 새 콘텐츠 탐험 월드를 만드세요.

버전 목록은 **게임 버전** 창을 열 때 다시 요청합니다. 요청에 실패하면 “목록을 새로 받지 못했습니다. 저장된 목록을 표시합니다.” 안내와 함께 이전 목록을 보여줍니다. 자동 업데이트의 15분 간격 제한은 수동 **지금 확인**에는 적용되지 않습니다. 공개 서버 응답에 5분 캐시 설정이 있으나 기기별 갱신 지연의 상한을 보장하지는 않습니다.

기계 베타 맵에서는 7×3×7 격자에 0.5m 차체·모터·바퀴를 배치합니다. 원점 차체를 기준으로 6면 연결된 모터·바퀴가 작동하고, 지면층 좌우 바퀴가 접지·조향을 제공합니다. 경량·중량 예제는 시험 자원을 초기화합니다. 주행 시작 후 WASD/방향키 또는 터치 방향 버튼으로 운전하고 Space/제동 버튼으로 감속합니다. 정지·조립으로 전환하여 격자 도구의 타격 시험·수리·제거를 사용합니다. 모터 HP는 출력, 바퀴 HP는 접지·조향에 반영됩니다. 장애물 충돌도 국소 HP를 감소시킵니다. 초록 광맥 (−6, 9) 근처에서 정지 후 채굴하면 조립·수리 재료를 얻습니다.

설계도와 부품별 HP·역학 상태를 분리했습니다. `machine/model.js`는 DOM/Three.js와 독립된 순수 모델, `machine/view.js`는 표현·입력 어댑터입니다. 책임·명령 흐름은 [docs/MACHINE-ARCHITECTURE.md](docs/MACHINE-ARCHITECTURE.md)에 기록했습니다. 기계 시험장은 60Hz 평면 간이 역학이며 3D 강체·서스펜션·전복·분리 파편·무장을 구현하지 않습니다. 기존 섬의 채굴 자원을 공유하지 않습니다. 15초마다 저장하며 목록으로 나가기·앱 비활성화 시에도 저장합니다.

```bash
node tests/machine-check.cjs
```

- 지형은 1m 기준을 유지하면서 수정한 칸만 8개의 0.5m 셀로 나눕니다. 표시·조준·충돌·채굴·설치·저장이 같은 반 칸 데이터를 사용합니다.
- 가방, 제작, 채굴 자원 드롭, 몹의 생체 복셀/전리품 드롭, 자동 수집, 재료를 사용하는 건축과 식생 복원을 추가했습니다.

## 설치와 업데이트

`Feral-0.2.5-android.apk`를 Android 기기에서 열어 설치합니다. Android 8.0 이상과 WebGL 2를 지원하는 최신 Android System WebView가 필요합니다. 0.1과 같은 applicationId와 시험 서명 키를 사용하며 versionCode를 205로 올렸습니다. 기존 앱을 지우지 않고 업데이트 설치하면 저장을 유지할 수 있습니다.

0.1 저장도 이어서 읽습니다. 기존 지형 수정·개체·분리된 신체 상태를 유지하고 가방에 시작 재료를 지급합니다. 축소된 몹에서 기존 부위의 손상 복셀 수가 달라지면 남은 비율에 맞춰 옮깁니다. 앱 데이터 삭제·앱 제거 시 저장은 삭제됩니다.

게임 자산을 APK에 포함합니다. 0.2.5부터 업데이트 통신을 위한 인터넷 권한만 추가했으며 저장소·위치 권한은 요청하지 않습니다. 토큰 연결 후 업데이트가 가능하고, 연결하지 않아도 현재 버전을 실행할 수 있습니다.

| 행동 | 모바일 | 키보드 |
| --- | --- | --- |
| 이동·시점 | 왼쪽 스틱·오른쪽 드래그 | WASD·마우스 |
| 점프·비행 | ↑·◇ | Space·F |
| 도구 선택·사용 | 아래 도구·오른쪽 사용 | 1~9·마우스 클릭 |
| 가방·제작 | 우측 상단 ▦ | I / Tab |

처음에는 1m 곡괭이가 선택되어 있습니다. 블록을 채굴하면 바닥에 자원이 떨어집니다. 드롭에서 약 1.5m 이내로 접근하면 가방에 자동으로 들어갑니다. 생명에 펄스를 사용하면 떨어진 복셀을 같은 방식으로 수집합니다. 몹이 죽으면 생명 정수나 결정 등의 전리품도 생성됩니다.

가방의 재료를 누르면 건축 재료로 선택됩니다. 흙·돌·원목·목재·모래는 0.5m 조각 단위입니다. 1m 블록을 설치하면 조각 8개, 0.5m 블록은 1개를 소비합니다. 캐릭터와 겹치거나 이미 채워진 공간에는 설치되지 않습니다. 씨앗 도구도 씨앗 1개를 소비합니다. 물·산과 개체 생성 도구는 실험용으로 계속 제공합니다.

| 채굴 도구 | 한 번의 범위 | 최대 부피 | 획득 |
| --- | --- | --- | --- |
| 정밀 끌 | 0.5 × 0.5 × 0.5m | 0.125m³ | 기본 장비 |
| 곡괭이 | 1 × 1 × 1m | 1m³ | 기본 장비 |
| 해머 | 2 × 2 × 2m | 8m³ | 돌 12 + 목재 4 + 생체 수지 2 |

목재는 원목 2개로 4개를 제작합니다. 생체 수지는 생체 복셀 6개로 2개를 만듭니다. 결정·수지·생명 정수를 모으면 강화 펄스도 제작할 수 있습니다. 재료가 모자라면 제작 버튼이 비활성화되며, 제작과 소비는 한 번에 처리합니다.

30초마다 자동 저장하며 메뉴의 **지금 저장**도 사용할 수 있습니다. 지형·반 칸 수정·가방·제작 장비·바닥 드롭·생태·플레이어 상태를 저장합니다.

## 세계와 시뮬레이션

- 시드 기반 160 × 160 × 40m의 유한한 섬, 강·숲·화산 지형·폐허와 5개 발견 장소.
- 이끼사슴·구리여우·청금딱정: 섭식·회피·포식·에너지·번식·죽음·토양 영양분·식생 회복.
- 복셀 제거, 연결 성분 분리, 부모 부위 손실 전파, 남은 다리에 따른 이동 속도 변화.
- 셀 유체의 중력·수평 이동과 물/산 혼합, 연소·소화·부식, 물과 용암의 현무암/수증기 반응.

물과 산은 여전히 1m 셀에서 계산합니다. 0.5m 틈을 정밀하게 통과하는 유체는 아직 지원하지 않습니다. 반응은 규칙 모델이며 실제 pH·분자 화학·압력/점성 유체 역학을 풀지 않습니다. 관절은 절차적 애니메이션과 파괴 가능한 부모 관계이며 완전한 강체 래그돌은 아닙니다. 무한 월드·멀티플레이·체력/허기 기반 생존 모드는 없습니다.

## 성능 구조와 한계

지형은 16 × 40 × 16 청크의 그리디 표면 병합을 사용합니다. 반 칸 데이터는 수정한 곳에만 할당하고 변경 청크만 재생성합니다. 가까운 개체부터 상세 복셀을 배정하며 먼 개체는 부위 단위 인스턴싱을 사용합니다. 생태 판단 주기는 거리별 0.25/1/3초이고, 유체와 반응에도 셀 예산을 둡니다.

개체 상한은 3,200마리, 드롭은 최대 600묶음입니다. 같은 종류의 가까운 드롭은 합쳐지며 240초 뒤 사라집니다. 가방은 자원 종류별 최대 9,999개입니다. 수천 개체가 모두 상세 복셀/전체 물리로 동시에 처리되는 구조는 아닙니다. 매우 낮은 프레임에서는 과도한 따라잡기 계산을 막기 위해 시뮬레이션 시간이 느려질 수 있습니다.

3,000개체에서 특정 FPS를 보장하지 않습니다. 휴대폰 실기기의 업데이트 설치·발열·배터리·장시간 플레이는 별도 검증이 필요합니다.

Java 17 JDK, Python 3, Android SDK Platform 35와 Build Tools 35.0.0이 필요합니다.

```bash
export ANDROID_HOME=/absolute/path/to/Android/sdk
bash build-apk.sh
```

결과는 `build/Feral-0.2.5-android.apk`입니다. 제공한 Gradle 프로젝트도 사용할 수 있습니다(Gradle 8.9 / AGP 8.7.3). `signing/prototype.keystore`는 재빌드용 공유 시험 키이며 배포용 서명은 별도로 관리해야 합니다.

웹에서 실행하려면 다음 서버를 시작하고 `http://localhost:8080`을 엽니다. APK에는 서버가 필요 없습니다.

```bash
python3 -m http.server 8080 --directory app/src/main/assets
node --test tests/*.test.js
```

브라우저 검증은 개발용 Playwright와 Chromium이 필요합니다.

```bash
FERAL_CHROME=/absolute/path/to/chrome node tests/browser-check.cjs
FERAL_CHROME=/absolute/path/to/chrome node tests/progression-check.cjs
FERAL_CHROME=/absolute/path/to/chrome node tests/updates-ui-check.cjs
```
