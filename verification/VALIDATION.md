# FERAL 0.2.5 검증 기록

검증일: 2026-10-16 (한국시간). 이전 기능 검증은 [0.2 기록](VALIDATION-0.2.md) 참고.

## 자동 검사

- Node 테스트 34개 통과. 기존 물리·채굴·생태·제작 30개에 네이티브 업데이트, 버전 일치, 실제 서명 패키지, 배포 순서·실패 검증 추가.
- 네이티브 UpdateCore를 실제 Java로 실행하여 세부 27개 검사 통과. 유효/변조 서명, APK 호환, 다운그레이드, 실패 버전 재적용, 다음 시작 적용, 시작 중 종료 복구, 저장 백업·복원 중 재종료, 이전 정상 다운로드 버전으로 복귀, ZIP 경로 탈출·누락·변조·크기 제한 포함.
- 실제 .feral 파일을 빌드해 APK에 고정한 RSA 공개 키로 서명 검증. 동일 소스에서 재생성한 업데이트 패키지의 바이트 일치 확인.
- Release 업로드가 실패하면 stable 브랜치를 변경하지 않는지, 모든 자산 업로드와 Release 게시 후에만 stable이 바뀌는지 검사.

결과: `test-results-0.2.5.txt`, `native-update-results-0.2.5.txt`.

## 화면·게임 회귀

Chromium + Playwright의 실제 WebGL 화면에서 기존 탐험·채굴·수집·공격·제작·건축·저장 복원과 0.1 저장 호환 재검증. 정지 상태의 발·카메라 높이 범위 0m, 눈높이 1.36m 유지.

업데이트 화면은 네이티브 연결을 모의하여 다음 동작을 확인했다. 게임/APK 버전 표시, GitHub 연결 호출, 지금 확인, 자동 확인 토글, 준비된 0.2.6 표시, 저장 성공 후 적용 호출, 저장 공간 부족 시 재시작 차단, 게임 준비 후 205 시작 성공 신호, 웹 미리보기에서 Android 전용 기능 비활성화. JavaScript 오류 없음.

결과: `updates-ui-results-0.2.5.json`, `progression-results-0.2.5.json`. 화면 테스트의 다운로드 준비 상태와 0.2.6은 검사용 모의 데이터이며 실제 0.2.6 릴리스를 배포한 것이 아니다.

## 검증의 한계

실제 휴대폰의 0.2 → 0.2.5 업데이트 설치, Android Keystore 토큰 등록, 비공개 GitHub API 다운로드와 WebView 생명주기를 연결한 실기기 종합 검증은 아직 수행하지 않았다. 네이티브 코어는 JVM에서, UI 연결은 브라우저의 모의 브리지에서 검증했다. 앱의 토큰 입력이 필요하므로 초기 APK만 설치하면 비공개 업데이트가 자동 인증되는 것은 아니다.

공유 시험 키를 유지하는 초기 비공개 프로토타입이다. 시작 실패 복구는 정상 시작 판정 전의 문제에 한정하며 모든 플레이 버그·저장 손상을 자동 복구한다고 보장하지 않는다.
