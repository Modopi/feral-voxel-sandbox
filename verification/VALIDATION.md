# FERAL 0.2 검증 기록

검증일: 2026-10-16 (한국시간).

## 진동 원인과 수정

0.1의 발 충돌 검사는 발보다 0.05m 위에서 검사했습니다. 바닥 안으로 내려간 상태를 먼저 허용하고 다음 검사에서 위로 보정할 수 있었습니다. 회귀 테스트에서 이 동작의 반복을 재현했습니다. 0.2는 1/60초 고정 물리, 실제 반 칸 충돌면을 사용하는 AABB 스윕, 접지 유지와 렌더 보간으로 교체했습니다.

단위 검증에서는 1,200틱 동안 접지 높이가 일정했고, 불규칙한 화면 프레임 간격에서도 카메라 높이가 일정했습니다. 실제 Chromium 화면에서도 18개의 렌더 프레임을 관찰한 결과 발 높이 범위 0m, 카메라 높이 범위 0m, 눈높이 1.36m였습니다.

## 자동 테스트

총 30개 통과. 기존 생태·물·반응 테스트에 접지 회귀, 점프 착지, 바닥 채굴 후 낙하, 0.5m 계단, 벽·천장 충돌, 반 칸 편집·메시·조준·저장, 도구별 0.125/1/8m³ 채굴, 제작 원자성, 전리품 수집, 장비와 드롭 저장 검증을 추가했습니다. 결과: simulation-results-0.2.txt.

## 화면에서 연결한 흐름

Chromium 131 + Playwright, 900×412 / 412×900 화면에서 실행했습니다.

- 1m 채굴과 0.5m 정밀 채굴: 선택한 반 칸이 비고 이웃 반 칸은 유지되는 것을 확인.
- 흙 보유량 16 → 25, 가까운 자원 자동 수집 확인.
- 펄스 공격으로 생체 복셀 드롭 생성과 가방 수집 확인.
- 가방에서 원목을 목재로 가공하고 생체 수지와 2m 해머 제작. 테스트 재료 일부는 반복 가능한 드롭 픽스처로 제공하고 실제 수집 경로를 거쳤습니다.
- 건축 크기 0.5m에서 흙 25 → 24, 반 칸 흙 블록 설치 확인.
- 다시 로드해 가방, 해머 제작 상태, 반 칸 지형, 설치한 블록 복원 확인.
- 0.1 형식 저장을 불러와 플레이 재개와 시작 재료 지급 확인.
- JavaScript 오류 0개. 결과: progression-results-0.2.json.
- 실제 터치 드래그로 가방 화면이 287px 스크롤되고 닫기 버튼이 계속 보이는 것을 확인했습니다. 결과: touch-menu-results-0.2.json.
- 3,000개체 생성·기본 이동·저장 복원을 별도 브라우저 스크립트에서도 확인했습니다. 해당 실행은 최종 출발 지점/도구 화면 위치 조정 전의 0.2 중간 빌드로 수행했으며 결과는 browser-results-0.2.json입니다. 최종 빌드의 수천 개체 이동 유한성은 30개 자동 테스트에 포함됩니다.
