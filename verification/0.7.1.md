# 게임 0.7.1 검증

2026-10-17 UTC. 게임 701 / 앱 303 / 최소 앱 303 / 저장 스키마 2. 배포 전 로컬 검증 기록.

## 자동 검증

- `node --test tests/*.test.js`: **100/100 통과**. 점프 최고 높이 1.28–1.33m, 1m 턱 넘기와 착지, 누른 상태의 자동 재점프 방지, 낮은 천장 충돌 포함.
- `node tests/world-ui-check.cjs`: 실제 지형으로 가려진 대상의 정보창 유지. 카메라 앞 불투명·반투명 평면을 추가한 뒤 GPU 픽셀을 읽어 정보창이 그 위에 그려지는지 검증. 가까운 창 너비 약 143px, 먼 창 약 95px로 원근 유지. 대상 이동·피해·사망·채굴·마을 상호작용과 세 가지 화면 크기 통과. JS 오류 0.
- `node tests/touch-look-check.cjs`: 실제 Chromium 터치 입력으로 900×412 / 360×640, 오른손/왼손, 공격·사용·상승·하강 **16개 드래그 조합** 통과. 버튼 밖 드래그 중 회전과 반복 동작/상하 이동, 손 떼기 후 해제 검증. 같은 버튼의 추가 손가락 해제, 이동 스틱+공격 드래그+별도 시점의 세 손가락 입력, 터치 취소, 일시정지 후 오래된 포인터 무시, 메뉴를 여는 사용 동작, 실제 포인터 캡처 상실을 검증. JS 오류 0.
- `tests/aerodynamics-movement-check.cjs`: 네이티브 CSP의 WASM 시작, 일반 JS 동적 평가 차단, 버전 701 시작 확인, 실패 버전 재시도 UI, 자세/천장/저장, 양손 배치, HUD 편집, 실제 기체 탑승·비행 조작 통과.
- `tests/interface-editor-check.cjs`: 배치 편집 드래그와 취소·크기·불투명도·저장 복원·방향별 배치·반 칸 마이그레이션 통과.
- `tests/survival-ui-check.cjs`: 인벤토리/핫바, 채굴·설치, 멀티터치 취소, 세 화면 크기와 왼손 조작, 먹이/번식 통과.
- 기존 파일 URL 검사에는 `FERAL_CHROME=/usr/bin/chromium`과 `/workspace/toolchain/browser-http.cjs` HTTP 어댑터 사용. 0.7.0 이하의 검증 산출물은 보존하고 새 결과만 이 폴더에 복사.

## 빌드와 호환성

- `node tools/version.mjs --check`, `git diff --check` 통과.
- `bash build-apk.sh`: Java 컴파일, Android SDK 35, APK v2/v3 서명과 zipalign 통과.
- 로컬 APK: `build/Feral-0.3.3-android.apk`, SHA-256 `eb8ffea73879f367d7e01281b75e1926c0fd34bb4ea6633aa8695f56ff958cfa`.
- `python3 tools/build-update.py`: 45개 자산, 2,755,815바이트 서명 패키지 생성.
- 패키지: `build/release/Feral-0.7.1-update.feral`, SHA-256 `e155c2fab7b4ea3fc5f41439355225a50b2e66b246d680e39a18aff84fbbfbe4`.
- Java·권한·검증 키·저장 스키마 변경 없음. 앱 0.3.3에서 OTA 적용 가능. 공유 시험 서명 유지.

실제 Android 기기를 연결한 터치·설치 검증은 수행하지 못했다. 위 모바일 입력과 화면 검증은 Chromium 터치 환경에서 실행했다. CI APK는 빌드 시각 때문에 로컬 APK와 해시가 다를 수 있으며 공개본은 Release 체크섬으로 별도 확인한다.
