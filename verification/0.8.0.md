# 게임 0.8.0 — 영속 손상·현장 상호작용·획득 순환 검증

2026-10-17 UTC. 게임 800 / 앱·최소 앱 303 / 저장 스키마 2. 배포 전 로컬 검증 기록이며 공개 패키지는 병합 후 별도로 검증한다.

## 손상과 월드 상호작용

- 반 칸별 손상은 조준·시간·도구·작업 범위 변경 후에도 보존. 혼합 재질은 각자의 강도로 파괴되고 보호 블록에는 손상이 누적되지 않음. 파괴·교체된 셀만 손상 제거, 중복 자원 지급 없음.
- 터치 공격 1회로 25% 손상을 남긴 뒤 시점·도구를 바꾸고 1.2초 기다려도 유지. 저장 후 재실행해 동일 비율 복원.
- 개척 지역을 이동했다 돌아온 뒤 30% 손상 복원. 수호자 격파·동맹·조립체·식량도 보존. 저장 용량 오류 시 이동·식량 차감 취소.
- 실제 화면 좌표를 탭하여 나무·열매·약초·고철 채집, 주민 대화·의뢰 전달, 세 중계기 해제와 회전 핵 회수, 동물 관찰·먹이·치료 실행. 가려진 유적 큐브 조준 차단, 재관찰·반복 사용으로 보상 증식 없음.
- 가방 가득 참, 먼 거리, 이미 완료한 의뢰·중계기·보상, 구 저장 진도 이전, 잘못된 상태 기록의 실패 경로는 모델 테스트로 검증.

## 획득 경로와 순환

`acquisition-loop.test.js`는 시작 지급품을 경로에 넣지 않는다. 기본 섬의 제공 아이템 21종과 개척 원정의 전체 아이템 44종에 재료·선행 연구 경로가 있으며 도달 불가능한 제작법은 0개다.

제작법 **47개 각각** 빈 가방에서 실제 채굴·재성장 채집·생명체 드롭·선행 연구·최종 제작을 실행했다. 합계 **685개 셀 채굴, 274회 채집, 29회 사냥**으로 모든 제작을 통과했다. 테스트에서 필요한 재료를 임의로 지급하지 않았다. 각 제작법은 독립 시나리오이며 한 플레이의 완주 시간이나 경제 균형을 측정한 것은 아니다.

비옥한 숲의 종별 개체수 복구, 플레이어와 거리 유지, 초식종이 있는 경우만 포식자 유입, 불모지 생성 금지, 이주 대기 시간 저장을 확인했다. 같은 지역에서 목재 재성장·식량 제작·돌/모래 교역·마을 재고 생산·퇴비 흙 제작도 실행했다. 연구 기록·핵·고철의 반복 제작 경로는 빈 가방 제작 검사에 포함된다.

## 화면 조작과 회귀

- `node --test tests/*.test.js`: **112/112 통과**.
- `content-interactions-check.cjs`: 위 현장 조작과 저장 재실행, 오류 0. 화면 밖 의뢰 버튼은 터치 스와이프로 노출 후 클리핑과 실제 히트 위치를 검사하고 탭. 테스트 자동 스크롤 클릭을 사용하지 않음.
- `menu-reachability-check.cjs`: 900×412, 640×360, 568×320, 360×640, 320×480에서 제작법 **47개 전체**에 실제 터치로 접근. 제작·슬롯 이동·분할·보관품 회수·작은 메뉴·월드 생성/이름 변경 조작 유지.
- `frontier-check.cjs`: 보급로 도보 이동, 교역·지원·동맹·연구, 수호자 조준 전투, 회전익 직접 조립·탑승·상승, 저장·지역 왕복과 오류 복구 통과. 기존 테스트의 이전 연구 명칭을 현재 항공 연구로 갱신.
- `structural-check.cjs`: 월드 면 부착·회수·합금 수리·주행·저장 복원·손상 동물의 기어 이동 통과.
- `touch-look-check.cjs`: 16개 화면 방향/손잡이/누른 버튼 조합의 시점 드래그, 같은 버튼 다중 터치, 이동 병행, 취소·일시정지·캡처 상실·메뉴 입력 해제 통과.
- `world-ui-check.cjs`: 정보창 원근·대상 추적·텍스처 재사용·지형과 투명 물체보다 우선 표시, 세 화면 크기의 상태창과 소모품 조작 통과.
- `survival-ui-check.cjs`: 기존 생존 인터페이스·마우스 드래그·터치 이동·채굴·설치·동시 조작 통과.

## 빌드

`node tools/version.mjs --check`, `git diff --check`, `bash build-apk.sh`, `python3 tools/build-update.py` 통과. APK v2/v3 서명, zipalign, APK·소스·서명 매니페스트 **47개 자산 해시 일치** 확인. 실제 해시는 [빌드 검증 JSON](0.8.0/build-verification.json), 빌드 로그는 아래 참조.

네이티브 Java·권한·키 변경 없음. 앱 0.3.3에서 게임 업데이트로 받으며 새 설치용 APK는 같은 네이티브 버전에 게임 0.8.0을 동봉한다. 저장 스키마 2의 선택 필드를 추가했고 기존 월드와 개척 상태 이전을 검증했다.

Android 실기기는 연결하지 못했다. 모바일 입력은 Chromium 터치 모사로 확인했으며 실제 WebView의 장시간 성능·열·배터리 검증을 수행한 것으로 간주하지 않는다. 릴리스 APK는 CI 빌드 시각에 따라 로컬 APK와 해시가 달라질 수 있다.
