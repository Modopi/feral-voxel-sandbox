# 개척 원정 0.4.0 검증

미배포 프로토타입. 네이티브 0.3.1 / 301 유지, 게임 0.4.0 / 400.

## 결과

- `node --test tests/*.test.js`: **55/55 통과**. 기존 물리·생태·가방·업데이트 서명/복구·기계 테스트 포함. 개척 모델 12개는 지역 재현, 지형 수정, 거래 원자성/거리/재고, 원거리 생산, 외교/경비, 보스 회피/피격/단회 보상, 유적, 연구 선행 조건, 기계 자원/손상/수리, 왕복 상태, 저장 검증, 사망·운동학/충돌을 다룸.
- `node tests/frontier-check.cjs`: 통합 통과. 실제 컨트롤러 이동으로 첫 마을에 접근 → UI 교역 → 목재 제작 → 지원 두 번 → 동맹 → 동력 연구. 전투·기계 검증은 명시적인 위치/재료 fixture를 사용하여 실제 조준·공격·조립 UI·비행을 확인.
- 지역 동쪽 이동과 복귀 후 지형 수정·수호자 격파·동맹·기계 유지. 식량 정확히 두 개 소비. 저장 quota 예외 주입 후 이동·식량 소비·기존 저장 모두 유지.
- 900×412, 412×900, 360×640에서 장부 네 탭의 가로 넘침 없음. JS 및 리소스 오류 없음. 별도 키보드 확인: Tab은 장부 안에서 이동, Escape는 닫기.
- 기존 `tests/progression-check.cjs`: 채굴·수집·제작·건축·저장/구버전 복원 통과, 오류 없음.
- 기존 `tests/machine-check.cjs`: 월드 생성·이름 변경·삭제·독립 저장·부품 손상/수리·주행·재로드·모바일 통과. 새 기본 월드 수를 반영하고 이름 기반 선택으로 수정.
- `bash build-apk.sh`: APK 생성, v2/v3 서명 및 zipalign 검증 통과.
- `python3 tools/build-update.py`: 게임 0.4.0 서명 업데이트 생성, 모든 게임 자산 포함. 외부 Release 게시 없음.

## 재현

```sh
python3 -m http.server 8080 --directory app/src/main/assets
node --test tests/*.test.js
FERAL_CHROME=/usr/bin/chromium node tests/frontier-check.cjs
```

기존 file URL 기반 브라우저 테스트는 실행 환경의 `/workspace/toolchain/browser-http.cjs` preloader로 로컬 HTTP 서버에 연결했다.

통합 결과: `frontier-results-0.4.0.json`. 화면: `frontier-boss-0.4.0.png`, `frontier-village-0.4.0.png`.
테스트 APK: `build/Feral-0.4.0-prototype-native-0.3.1.apk`. 서명 게임 패키지: `build/release/Feral-0.4.0-update.feral`.
