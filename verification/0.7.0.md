- `node --test tests/*.test.js`: **99/99 통과**. 기존 89개와 항공/자세 10개. 네이티브 업데이트 하위 검증은 **56개**, 공개 전송 검증은 15개다.

- `tests/structural-check.cjs`: 모바일 월드 조립·회수·수리·저장과 실제 주행, 동물 다리 손상 표시 통과. 차량 이동 5.06m, JS 오류 0.
- `tests/interface-editor-check.cjs`: 드래그·취소·크기·불투명도·저장 실패·방향별 배치·반 칸 마이그레이션·월드 생성 통과.
- `tests/updates-ui-check.cjs`: 시작 확인, 공개 업데이트/버전 선택, 자동 확인 토글, 적용 전 저장과 저장 실패 시 적용 중단 통과.
- `tests/survival-ui-check.cjs`: 900×412, 412×900, 360×640 인벤토리·핫바·터치 조작·화면 가림 검사 통과.
- 위 기존 브라우저 스크립트는 `FERAL_CHROME=/usr/bin/chromium`, HTTP 자산 서버(필요한 파일 URL 스크립트에는 `/workspace/toolchain/browser-http.cjs` 어댑터)로 실행했다.

항공 단위/통합 검증은 양력의 속도 제곱 비례, 실속, 에너지 증가 없는 수동 힘, 내부 면 항력 제외, 기수·선회 입력 방향, **활주 이륙**, 한쪽 날개 손실의 회전 변화, 모터 파괴의 추진 중단, 조각/바람, 항공 부품 제작과 저장을 포함한다. 자세 검증은 0.5m/1m 통로, 머리 공간, 시야, 속도, 조립체 아래 일어서기 제한을 포함한다.

재시도는 손상 패키지 거부, 최소 앱 검사 유지, 자동 재시도 불허, 검증 후 권한의 프로세스 재실행 유지, 두 번째 실패의 저장 복구, 성공 후 실패 표시 해제, 동봉 버전 오프라인 재시도를 검증했다.
