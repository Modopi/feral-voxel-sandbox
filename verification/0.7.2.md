# 게임 0.7.2 — 실제 터치 스크롤 검증

2026-10-17 UTC. 게임 702 / 앱 303 / 최소 앱 303 / 저장 스키마 2. 아래는 배포 전 로컬 검증 기록.

## 재현과 수정

0.7.1의 제작 타일은 `touch-action:none`이라 아이콘에서 시작한 스와이프가 차단되었다. 세로 화면 제작 목록은 가로로만 배치되어 아래로 넘길 수 없었다. 슬롯의 포인터 캡처도 인벤토리 스크롤과 충돌했다. 900×412, 640×360, 360×640, 320×480에서 실제 드래그 후 제작 목록 스크롤 이동량이 0인 것을 [기존 결과](0.7.2/scroll-before.jsonl)로 기록했다.

제작 목록을 양쪽 화면 방향 모두 세로 스크롤로 바꾸고 인벤토리와 각각 뷰포트 안에서 높이를 제한했다. 닫기는 고정하고 슬롯은 모바일 스와이프와 탭 이동을 구분한다. 제작·아이템 이동 후 목록 위치를 보존하며 필터 변경 시 처음으로 이동한다. 세로 메뉴 탭의 가로 터치 제한과 작은 월드 대화창의 높이도 수정했다.

## 실제 좌표 조작

`node tests/menu-reachability-check.cjs` 통과. **테스트 도구의 자동 스크롤 클릭, scrollIntoView, scrollTop 대입 없이** Chromium 터치 스와이프를 전송한다. 대상이 뷰포트와 모든 조상 클리핑 영역에 완전히 들어왔는지 확인하고 `elementFromPoint`로 가림을 검사한 실제 화면 좌표를 탭한다. 데이터 준비만 API를 이용하며 제작·이동·메뉴 동작은 화면 입력으로 실행한다.

- 900×412, 640×360, 568×320, 360×640, 320×480에서 **제작법 37개 모두** 노출·히트 테스트 확인. 마지막 제작법 선택 후 실제 제작과 재료 차감 확인.
- 아이콘/슬롯에서 시작한 스와이프가 스크롤되며 제작·아이템 이동을 일으키지 않음. 슬롯 선택 후 스크롤하여 핫바로 이동·교환, 하단 보관품 회수 확인.
- 제작/슬롯 이동 후 스크롤 유지, 제작 필터 변경 후 처음으로 이동.
- 화면 높이 320px에서 세로 탭을 스와이프해 업데이트 선택. 설정 아래쪽 왼손 체크박스, 상태창 회복약, 기계 안내 펼치기와 닫기 조작.
- UI 편집기 하단 초기화 버튼을 스와이프 후 탭. 게임 좌표 유지 확인.
- 긴 월드 목록 마지막 항목까지 스와이프 후 이름 변경. 568×260으로 줄어든 뷰포트에서 새 월드 대화창을 스크롤하여 생성 확인.
- JavaScript 오류 0.

- `node --test tests/*.test.js`: **100/100 통과**.

- `tests/interface-editor-check.cjs`: 편집·저장·취소·방향 전환·반 칸 이전·월드 생성 통과.

- `node tools/version.mjs --check`, `git diff --check` 통과.
- `bash build-apk.sh`: SDK 35 컴파일, APK v2/v3 서명과 zipalign 통과.
- 로컬 APK: `build/Feral-0.3.3-android.apk` / SHA-256 `63ae5958015fc62b947e16d5d5e8cbfa5e26694cc857e4663c7688943dac7120`.
- `python3 tools/build-update.py`: 45개 자산, 2,756,503바이트 서명 패키지.
- 패키지: `build/release/Feral-0.7.2-update.feral` / SHA-256 `0ff5b6fca161a1a31face5a04ef6bce4469b42c5e5d83fe50618825466d88f28`.
