# 0.15.3 개척 지역 지형과 사망 규칙 설정 (통합 S2a) 검증

게임 0.15.3 / 1503, 네이티브·최소 네이티브 0.3.3 / 303, 저장 스키마 2. 게임 파일만 바꾼 릴리스다. 기준은 [소프트웨어 구조](../docs/ARCHITECTURE.md) 5장, [로드맵](../docs/ROADMAP.md)의 S2 결정과 S2a 단계, [게임 규칙](../docs/GAME-RULES.md) 5장이다.

## 사용자 요청과 결정

| 요청·결정 | 0.15.3 |
| --- | --- |
| 엔진 통합(S1→S2→S3)을 먼저 끝내고 성능 최적화 | S2를 네 조각(S2a~S2d)으로 나눠 배포한다. 이번이 첫 조각이다 |
| 생존: 통합 런타임 규칙 | 로드맵·구조 문서에 기록. 캠페인 보상의 아이템·연구 변환은 S2b |
| 사망: 월드 설정으로 선택 | 월드 설정 "사망 시 소지품 남김"을 만들었다. 콘텐츠 탐험·기본 섬 기본 켬(지금과 같음). 개척 원정 프리셋은 통합 런타임으로 옮길 때(S2d) 기본 끔으로 연다 |
| 지역: 한 월드 안의 섬들 | 지형 생성기 `frontier`가 개척 원정 지역을 320 m 간격의 섬으로 놓는다. 지역 이동 버튼(식량 1개, 다시 읽기 없음)은 S2b |

## 바뀐 것

- 월드 설정 `dropOnDeath`(언제든 바꿀 수 있음):
  - 켬: 소지품·든 무기를 쓰러진 자리에 남기고 10 m 안에서 요정이 돌려준다(지금 동작).
  - 끔: 소지품을 지닌 채 깨어난다.
  - 깨어나는 곳은 생성기가 정한다. `respawn(x, z)`가 있으면 그 위치(개척 원정 지형: 가장 가까운 지역 야영지), 없으면 시작 위치. 메시지는 시작 위치 이름(출발지·상륙 지점·지역 야영지)을 쓴다.
  - 세계 패널 설명에 지금 사망 규칙을 덧붙인다.
- 지형 생성기 `frontier`(`content-runtime/maps.js`의 `FrontierAtlas`):
  - 지역 `(rx, rz)`는 `frontierWorld(regionInfo(seed, rx, rz).seed, …)`의 칸을 그대로 `(rx·320, rz·320)` m에 놓는다. 사이는 바다다. 지역 등급은 `regionInfo`의 등급이다.
  - 지역 지형은 최근 6개만 메모리에 둔다. 옛 개척 원정 저장에서 온 지역의 지형 버전(`regionTerrain`)은 지형 상태에 저장한다.
  - 지역마다 야영지 둘레 시작 채집물이 있다(id `starter:rx,rz:…`).
  - `regionInfo`·`regionKey`를 `frontier/model.js`에서 `frontier/terrain.js`로 옮기고 `model.js`는 다시 내보낸다(내용 그대로).
- `IslandAtlas`를 섬 여러 개를 담을 수 있게 일반화했다(`_islandAt`·`_landings`). 기본 섬의 칸·채집물 id·값은 그대로다(아래 섬 테스트).

## 성능 측정

기본 섬 지형 코드(`IslandAtlas`)가 섬 조회를 한 번 더 거치게 되어 섬 장면을 0.15.2와 같은 도구로 차례로 쟀다([측정](0.15.3-perf.json)). Chromium SwiftShader 수치이며 실기기 수치가 아니다. "게임 JS"는 두 버전에 모두 있는 메서드(월드 갱신·물리 단계·플레이어 이동·물리 동기화·지형 메시·모델 갱신·그리기 호출·청크 생성·환경 표시)의 프레임당 시간 합이다.

| 장면 | 게임 JS 0.15.2 | 게임 JS 0.15.3 |
| --- | --- | --- |
| 섬 대기 | 15.6 ms | 14.2 ms |
| 섬 걷기 | 17.5 ms | 16.0 ms |
| 나무 채굴 1·2·3 | 14.1 · 9.9 · 8.5 ms | 13.3 · 8.3 · 7.8 ms |
| 분리된 나무 옆 | 9.3 ms | 10.0 ms |
| 분리된 나무 옆 걷기 | 12.8 ms | 8.4 ms |

두 빌드 차이는 측정 흔들림 안이며 느려진 장면은 없다. 프레임 루프·물리·생물·렌더 코드는 바꾸지 않았다.

## 한계

- 개척 원정 프리셋은 아직 옛 엔진이다. `frontier` 생성기는 테스트와 이후 단계에서만 쓰이며 런처에서 고를 수 없다.
- 개척 원정 지역의 마을·수호자·캠페인·지역 이동은 S2b, 충격·낙하 피해와 기계·지형 물체 보충은 S2c, 프리셋 전환과 저장 변환은 S2d다.
- 사망 규칙을 끈 상태의 화면 사망 장면은 브라우저로 확인하지 않았다(런타임 테스트로 확인).
