# 0.15.5 충격·낙하 피해 (통합 S2c1) 검증

게임 0.15.5 / 1505, 네이티브·최소 네이티브 0.3.3 / 303, 저장 스키마 2. 게임 파일만 바꾼 릴리스다. 기준은 [게임 규칙](../docs/GAME-RULES.md) 5장의 충격 피해, [소프트웨어 구조](../docs/ARCHITECTURE.md) 7장, [로드맵](../docs/ROADMAP.md)의 S2c다.

## 사용자 결정과 0.15.5

| 결정 | 0.15.5 |
| --- | --- |
| 옛 엔진에만 있던 기능은 버리지 않고 통합 런타임으로 옮긴다. 화면·조작 감각의 기준은 개척 원정 | 개척 원정의 충격 규칙(`impact.js`)을 그대로 쓴다: 낙하 안전 속도 8 m/s·80 kg 몸, 물체 안전 속도 4 m/s, 플레이어 피해 = 에너지 ÷ 140(최대 100), 생명체 피해 = 에너지 ÷ 100(최대 80) |
| 생존: 통합 런타임 규칙 | 피해는 `runtime.hurt`로 가고 장비 피해 감소가 적용된다. 생존을 끈 월드는 피해가 없다 |

생존이 켜진 기존 월드(콘텐츠 탐험 기본값)는 이번부터 낙하와 날아온 물체에 피해를 받는다. 개척 원정 감각을 기준으로 한 규칙 변경이며 CHANGELOG·게임 규칙·설치 안내에 적었다.

## 바뀐 것

- `runtime.js`
  - `impactDamage(energy, source)`: 플레이어 피해 계산과 적용(생존·장비 감소).
  - 고정 단계마다 지난 단계의 낙하 속도를 기억하고, 땅에 닿은 단계에 8 m/s를 넘으면 피해와 "낙하 충격" 알림. 기계에 탄 동안과 비행 중은 0.
  - `strikePlayer(energy, sourceId)`: "물체 충돌" 알림. `strikeCreature(id, partId, energy, point, sourceId)`: 맞은 부위의 뼈에 둔기 타격(`attackMode: 'impact'`).
- `physics.js`
  - `playerImpacts`: 세계 단계 뒤·포착 전에, 지형 물체와 기계의 지난 포착 상태(충돌 전 속도·위치)로 접근 속도 4 m/s와 거리를 먼저 보고, 그때만 플레이어 캡슐과 충돌체를 정확히 시험한다. 같은 몸체는 0.45초에 한 번. 들고 있는 물체와 타고 있는 기계는 제외.
  - `creatureImpacts`: 4 m/s보다 빠른 지형 물체만 접촉 쌍을 조회해 생명체 부위에 닿았는지 본다. 같은 물체·생명체 쌍은 0.45초에 한 번.

## 성능 측정

물리 단계에 판정을 더해, 0.15.4와 같은 도구로 섬·콘텐츠 탐험 장면을 차례로 쟀다([측정](0.15.5-perf.json)). Chromium SwiftShader 수치이며 실기기 수치가 아니다. "게임 JS"는 두 버전에 모두 있는 메서드의 프레임당 시간 합이다.

| 장면 | 게임 JS 0.15.4 | 게임 JS 0.15.5 | 물리 단계 0.15.4 | 물리 단계 0.15.5 |
| --- | --- | --- | --- | --- |
| 섬 대기 | 16.2 ms | 17.9 ms | 3.09 ms | 4.01 ms |
| 섬 걷기 | 16.6 ms | 17.6 ms | 2.85 ms | 3.49 ms |
| 나무 채굴 1·2·3 | 14.7 · 13.4 · 9.6 ms | 14.4 · 11.4 · 8.2 ms | 2.48 · 2.36 · 1.97 ms | 2.18 · 1.82 · 1.68 ms |
| 분리된 나무 옆 | 12.4 ms | 12.5 ms | 2.71 ms | 2.09 ms |
| 분리된 나무 옆 걷기 | 10.2 ms | 9.0 ms | 1.89 ms | 1.53 ms |
| 콘텐츠 탐험 대기 | 16.1 ms | 16.7 ms | 2.44 ms | 2.87 ms |
| 콘텐츠 탐험 걷기 | 18.9 ms | 19.1 ms | 3.22 ms | 3.30 ms |

섬 대기·걷기는 물리 단계가 늘었고 물체가 있는 장면은 줄어 방향이 일정하지 않다. 섬 대기의 물리 단계는 물리 코드를 바꾸지 않은 0.15.2·0.15.3 측정에서도 2.4~3.1 ms로 흔들렸다. 새 판정만 따로 Node에서 섬 월드로 재면 움직이는 몸체가 없을 때 물리 단계마다 0.00024 ms로, 같은 환경의 물리 단계 전체(0.059 ms)의 약 0.4%다. 차이는 측정 흔들림으로 본다.

## 한계

- 물체가 지형 칸·기계 복셀을 부수는 충돌과 기계 충돌 피해(개척 원정 `impact-physics.js`)는 아직 없다(S2c2).
- 생명체끼리, 생명체가 플레이어를 치는 충돌은 이번 범위가 아니다(생명체 공격은 기존 공격 규칙).
- 브라우저에서 실제로 떨어져 피해를 받는 화면 장면은 확인하지 않았다(런타임·물리 테스트로 확인).
