# 0.19.1 검증 — 런처에서 실제 플레이까지

게임 1901 / 앱 0.4.1·401 / 최소 앱 401 / 저장 스키마 5. 공개 배포는 아직 대기 중이다. 이 문서의 로컬 검사를 Android 휴대폰 실행 결과로 해석하지 않는다.

## 재현한 원인과 수정

- Android `LegacyWebViewExporter.HTML`의 IndexedDB 분기에 닫는 괄호가 빠졌다. APK에 삽입되는 정확한 문자열을 추출해 실행하면 `SyntaxError: Unexpected token ')'`가 발생한다. 따라서 빈 설치도 저장 확인을 완료하지 못하고 `legacy_import_pending_`으로 월드 진입이 차단됐다. 괄호를 복구하고 스크립트 자체를 검사한다.
- 이전 smoke/UI 검사는 `_ready()`에서 `start_world("native-smoke")`를 직접 호출했다. 런처 버튼·Android 저장 확인 단계는 이 검사에서 다루지 않았다. 새 검사는 정상 `_ready()`와 실제 GUI/Input 이벤트를 사용한다.
- 실제 지형 타격에서 잔디·흙의 정식 `materialId: null`을 문자열로 읽어 `json.exception.type_error.302`가 발생하고 일시정지 화면으로 넘어갔다. nullable 참조를 명시적으로 처리한다. 성공한 접촉만 타격 횟수로 기록한다.
- 터치는 `_unhandled_input`의 이동/시점 두 번호와 마우스를 흉내 내는 단일 버튼 입력에 의존했다. 새 `InputState`와 `_input` 어댑터는 손가락별 소유권, HUD 동시 조작, 취소·포커스 상실·화면 전환을 처리하며 합성 마우스 중복을 차단한다.
- 빈 저장 확인에서 가짜 기본 월드 목록이 생기지 않도록 했다. 저장 확인 실패·빈 결과는 재시도를 표시하며, 확인 완료 전 새 월드 기록을 쓰지 않는다. 원본 저장 아카이브는 보존한다.

## 완료한 로컬 검사

- `npm test`: 531개 통과.
- 정확한 Android 저장 스크립트: 11개 통과. 빈 설치, 이전 IndexedDB API, localStorage, 보관함 커서, 누락된 저장소, 64 KiB 이상 분할, 출력/DB 실패를 포함한다.
- Storage 집중 검사: 통과. 빈 export는 보존하되 월드 0개를 유지하고, 완료 표시와 실패 후 재시도가 동작한다.
- 정상 런처 경로: 저장 확인 대기 → 빈 결과 오류 → 재시도 → 완료 → 시작 소지품 선택 → 터치 스크롤 → 새 월드 생성 → 이동/시점/세 번째 손가락 타격 → 실제 지형 파괴 → 점프 → 키보드 이동 → 메뉴/포커스 입력 해제 → 저장/나가기 → 이어가기.
- 별도 Godot 프로세스에서 저장한 세계를 다시 열어 같은 worldId와 플레이 위치 복원을 확인했다. 저장 완료 후 매번 가져오기로 다시 막히지 않는 것도 검사한다.
- llvmpipe 실제 렌더링에서 1280×720 및 844×390 창으로 실행. [모바일 크기 화면·결과](0.19.1-native-ui/)를 남겼다. 이동/시점/타격 3개 포인터가 동시에 유지됐고, 지형 접촉 24회가 성공한 뒤 플레이가 계속됐다. 기본 맨손 시작과 시작 소지품으로 곡괭이를 든 경로 모두 로컬 실행했다.
- 이전 JS 화면 회귀: 오류 0개. [기록](0.19.1-ui/)은 이전 런타임 검사이며 네이티브 검사를 대신하지 않는다.

## 확인 범위와 남은 모바일 입력

런처 검사는 실제 C++ 씬·Godot GUI·Jolt를 실행하지만 Android 저장 브리지는 대역이다. 정확한 WebView 스크립트는 별도로 실행하며, 데스크톱에서는 터치 가능 화면 힌트를 켜서 ScrollContainer의 실제 터치 경로를 탄다. 연결된 Android 기기가 없어 APK 설치·Android WebView 수명주기·휴대폰 터치 전달·발열/FPS는 확인하지 않았다.

이동·시점·점프·타격·HUD는 공용 입력 경로를 사용한다. 모든 조작의 모바일 동등성이 완성된 것은 아니다. 달리기는 Shift, 기계 하강·제동은 Shift/Q/Control 전용이며 모바일 상승은 점프의 한 단계 입력이다. 연속 상승·하강·제동 터치 조작과 게임패드는 남아 있다.
