# 0.9.0 — 첫 신호·시각 표현 개편 검증

2026-10-17, Linux / Node / headless Chromium + SwiftShader. 게임 900, 네이티브/최소 앱 303, 저장 스키마 2.

## 실행 범위와 결과

- `node --test tests/*.test.js`: **118/118 통과**. 캠페인·저장·원자적 보상·전투 예고·기존 생태/물리/업데이트 검사를 포함한다.
- 초기 지급품 없는 전체 제작 실행: **50개 제작법**, 채굴 686셀·채집 281회·사냥 29회. 별도의 의존 경로 검사에서 **46종 아이템 모두 접근 가능**. 식물 수지는 사냥 없이도 기계 재료를 만드는 대안이다.
- 초기 지급품 없는 첫 신호 캠페인 실행: 실제 채굴/채집/제작/교역 명령으로 여섯 목표, 탐사·수호자·협력 세 신호 경로, 송신탑, 측량·보급·잔향 세 원정을 완료했다. 채굴 15셀·채집 11회·제작 9회·공격 14회·3지역·사망 0회·모델 시간 365초. 이동 위치와 시뮬레이션 시각을 테스트가 제어하므로 이 수치는 사람의 완주 시간이나 무이동 조작 플레이를 뜻하지 않는다. 각 단계 저장 왕복도 검사했다.
- 메뉴 접근 검사: **900×412, 640×360, 568×320, 360×640, 320×480**에서 제작법 50개 모두 노출. 브라우저 스와이프와 노출된 좌표 탭으로 제작·슬롯 이동·수리·보관품 받기·설정·상태·기계 설명·UI 편집·월드 생성/이름 변경을 실행했다. `scrollIntoView`나 강제 스크롤 위치 지정으로 성공시키지 않았다.
- 기존 현장 상호작용: 조준 이탈과 저장 후 채굴 손상 보존, 채집 4종, 주민 의뢰, 벽 너머 사용 차단, 중계기 3개와 유적 보상 중복 방지, 동물 관찰·먹이·치료·저장 통과.
- 기존 원정: 마을까지 물리 보행, 교역·동맹·연구·수호자 전투, 월드 부품 조립·회전익 상승, 지역 왕복 시 손상/보스/기계/동맹 유지, 저장 실패 시 이동/식량 차감 롤백 통과.

- 새 캠페인 터치: 새 저장에서 채집 3곳 → 목표 보상 → 텃밭 건설 → 파종 → 수확 → 스튜 제작 → 저장/재실행 통과. 다섯 뷰포트에서 여정 버튼 16개씩 노출을 확인했다. 후반 해금 상태를 준비한 뒤 측량 표석 3곳 사용·귀환 보상, 버튼 유지 공격으로 잔향 격파·귀환 보상을 실행했다.
- 버튼 드래그: 공격·사용·점프·하강의 누름/반복/시점 회전/해제를 가로·세로·양손 배치에서 검사. 같은 버튼의 두 손가락, 이동 스틱 동시 입력, 취소·일시정지·캡처 해제까지 통과.
- 월드 UI: 원근과 대상 추적, 벽 앞 우선 표시, 네 가지 화면의 상태창 뷰포트/내부 스크롤·소모품 사용·인벤토리 이동 통과.
- 그래픽: 낮음/균형/높음에서 셰이더·페이지 오류 0건. 진단 장면의 화면 렌더 호출 178/178/182회, 삼각형 33,758/46,418/51,986개, 텍스처 3개. 서버 SwiftShader 중앙 프레임 시간 300/350/417ms는 실제 기기 성능 기준으로 사용하지 않는다.

- 기존 생존 UI: 보이는 슬롯으로 스크롤 후 마우스 드래그, 터치 분할/합치기, 실제 버튼 채굴·설치·동시 조작·취소·재실행 통과. 세로/가로/왼손 배치의 슬롯 9칸과 조작 영역을 확인했다.
- 기계/동물: 월드 부품 부착·자원 차감·실제 주행·저장 복원·다리 손상 행동 검사 통과.
- 대각선 돌진: +Z/-Z 두 방향에서 실제 3D 예고 메시를 역변환하여 타격 도형의 중심선과 일치함을 확인했다. 렌더 각도 부호 오류를 수정했다.

완성 야영지의 시각 검사 준비 화면은 `0.9.0/final-balanced.png`이며, 조작을 건너뛰어 보상 조건을 검사하는 자료가 아니다.

새 캠페인의 화면 조작과 그래픽 품질별 결과는 `0.9.0/campaign-browser.json`, 메뉴 접근은 `0.9.0/menu-reachability-results.json`에 기록한다. 모델의 전체 캠페인 검사와 브라우저의 조작/배치 준비 데이터를 구분한다. 후반 원정의 화면 검사는 해금 상태를 준비하고 실제 버튼으로 진행하며 새 게임부터 사람이 걸어 완주한 기록은 아니다.

## 시각 표현

Minecraft의 형태 보존과 조명 개선, Valheim의 단순한 형상과 분위기, Terraria의 아이콘/텍스트 계층을 비교했다. 실제 적용과 출처는 [설계 문서](../docs/archive/FIRST-SIGNAL.md)에 정리했다. 외부 게임의 시각 자산을 복사하지 않았다.

- 청크 병합/반 칸 지형 위에 절차적 풀·나뭇결·나이테·석재·모래·광석 표면. Standard 표면 조명, 국소 그림자, 하늘/안개/주야 색조, 수면 물결.
- 주민 얼굴·작업 소품, 채집물과 지역 수호자 실루엣, 손 도구·기계 재질.
- 공통 청록·황동 팔레트, SVG 행동/월드/아이템 그림, 이름 있는 제작 슬롯과 검색, 고정 프레임 안에서 넘기는 여정 화면.
- 낮음/균형/높음 품질별 그림자 OFF/1024/2048, DPR 상한 1/1.5/2. SwiftShader 프레임 시간은 서버의 소프트웨어 렌더 진단값이며 휴대폰 FPS가 아니다.

## 빌드·호환성과 한계

`bash build-apk.sh`와 `python3 tools/build-update.py` 통과. APK의 v2/v3 서명·정렬 확인. 게임 업데이트에는 **53개 검증 파일**이 들어간다. 공유 시험 키는 기존 키를 유지한다. 네이티브 변경이 없으므로 앱 0.3.3에서 게임 업데이트로 적용한다.

구 저장은 여정·시설의 기본값을 부여하고 기존 지역 지형 버전을 유지한다. 새로 방문하는 지역에 새 유적 구조를 만든다. 농업·신호·원정·버프는 저장되며 오프라인/메뉴 시간에 진행되지 않는다. 가방이 꽉 차면 수확과 보상은 사라지지 않는다.

이 결과는 **콘텐츠 완주 가능한 베타 후보**의 자동 검사다. 실제 Android 설치/터치/장시간 플레이, 발열·배터리·메모리·프레임 안정성, 사람의 난도/가독성 평가는 수행하지 않았다. 시설은 상태에 따라 나타나는 월드 모델이며 직접 복셀을 붙여 짓는 기계 조립과 별도다. 무중단 무한 월드와 개인별 주민 경제·전쟁은 이번 범위가 아니다. 공개 게시 결과는 병합 후 GitHub Release와 updates 채널에서 추가 검증한다.
