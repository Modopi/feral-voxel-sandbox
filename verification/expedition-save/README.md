# 탐험 자동 저장 워커 검증

2026-10-17, 실제 고티어 자원 소비 경로에서 보존한 고정 스냅샷으로 검사했다. 원본은 `complete`, `reached`, `progression`, `atlas`를 포함하며, 검사에 필요한 유한 플레이어 좌표와 HP만 추가했다. 압축된 재현 입력은 [high-tier-route.json.gz](high-tier-route.json.gz), 입력 해시·코드 해시·전체 결과는 [profile.json](profile.json)에 있다.

## 구현 계약

- `Autosave.schedule(state)`는 즉시 불변 JSON 스냅샷을 만들고 모듈 Worker에 보낸다. 문자열화와 메시지 전송은 메인 스레드에 남는다. 압축, 압축 해제 및 저장 내용 검증은 워커가 처리한다.
- 메인 스레드는 검증된 압축 봉투의 체크섬/세대를 확인하고 비활성 슬롯에 쓴 뒤, 읽어 온 원문 전체가 작성 원문과 일치하는지 확인한다. 기존 활성 슬롯은 수정하지 않는다. 실패한 비활성 슬롯은 가능한 경우 이전 원문으로 복원한다.
- 실행 중 1개와 최신 대기 1개만 유지한다. 더 최근 요청이 있으면 오래된 결과는 쓰지 않는다. `writeNow`는 진행 중 워커를 취소하고 최신 상태를 동기 저장한다. 별도 `ExpeditionSave.write` 또는 `load` 호출도 revision 변경으로 이전 자동 저장을 무효화한다.
- Worker 생성/로딩/메시지 처리 실패 또는 Worker 미지원은 지연 실행한 동기 준비로 안전하게 대체한다. 이 경로는 압축 지연을 제거하지 못한다.
- 이전 비압축 JSON 저장과 현재 UTF-16 압축 저장은 모두 읽는다. 저장 스키마는 1을 유지한다.

## 실제 브라우저 관측

동일 입력으로 동기 저장과 워커 저장을 번갈아 3회씩 실행했다. 각 회차마다 저장을 새 `ExpeditionSave`로 다시 읽고 원본 JSON 전체와 일치를 확인했다. 쓰기 완료 후 검증용 읽기/비교 작업은 측정 구간에서 제외했다.

| 항목 | 동기 저장 3회 | 워커 자동 저장 3회 |
| --- | --- | --- |
| 메인 호출 시간 | 1,594.5–2,678.3 ms | 30.8–66.2 ms |
| 메인 스레드 50ms 이상 작업 | 3회, 최대 2,678 ms | 1회, 최대 66 ms |
| 압축 준비를 포함한 전체 완료 시간 | 1,594.5–2,678.3 ms | 1,031.3–2,004.5 ms |
| 메인 저장 확정 시간 | 동기 호출에 포함 | 2.8–15.5 ms |

두 세대 합계는 **394,102 UTF-16 문자**, 브라우저 오류는 0개, 6회 모두 전체 데이터가 일치했다. 워커 저장도 JSON 문자열화와 저장소 접근 때문에 잠깐 지연될 수 있다. 모든 프레임이 16.7ms 이내라는 결과가 아니다.

측정은 공유 실행 환경의 데스크톱 Chromium에서 렌더러·게임 루프 없이 저장 서비스만 실행했다. 실제 Android 기기 또는 모바일 메모리/프레임 검증이 아니다. 동시 실행 작업의 CPU 경합이 있고, `runtime.serialize()` 비용은 기존 메인 스레드에 남으며 이번 범위에 포함하지 않았다.

## 회귀 및 재현

`node --test tests/expedition-save.test.js tests/expedition-autosave.test.js`: **10개 통과**. 기존 저장 3개를 유지하면서 최신 요청 병합, 수동 저장 우선, 수동 저장 실패 시 오래된 자동 저장 금지, 직접 저장 호출, 실제 백그라운드 워커 왕복, Unicode/소수/25,000개 원장 보존, 용량 오류, 잘림, 다른 정상 원문으로 치환, 잘못된 워커 응답, 워커 대체 경로, 종료 후 쓰기 금지를 검사한다.

저장소 루트를 HTTP 8081로 제공한 다음 `node tools/profile-expedition-save.mjs`로 재현한다. `FERAL_PROFILE_URL`, `CHROMIUM_PATH`, `FERAL_SAVE_FIXTURE`로 환경을 바꿀 수 있다. 기본 입력은 저장된 gzip 원본이다. 실행은 별도 `feral.save-profile` 키만 사용하고 종료 시 삭제한다.
