## 구현 제한

기계 시험장은 평면 집계 역학으로, 3D 강체/전복/서스펜션/무장/물리적 파편 분리는 없다. 기능적 연결은 원점 차체와의 6면 연결을 기준으로 평가한다. 기존 탐험 월드와 기계 시험장은 동일한 목록·저장 선택 계층을 사용하지만 서로 다른 시뮬레이션을 실행한다.

Android 실기기 조작·업데이트 설치·장시간 발열·배터리는 검증하지 않았다. GitHub 게시와 자동 업데이트 채널 갱신은 수행하지 못했다.
