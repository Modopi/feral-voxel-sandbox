# 0.15.6 로터 비행과 개척 원정식 물체 잡기 (통합 S2c2) 검증

게임 0.15.6 / 1506, 네이티브·최소 네이티브 0.3.3 / 303, 저장 스키마 2. 게임 파일만 바꾼 릴리스다. 기준은 [게임 규칙](../docs/GAME-RULES.md) 2장(물체 잡기)·6장(기계 비행), [로드맵](../docs/ROADMAP.md)의 S2c다.

## 사용자 결정과 0.15.6

| 결정 | 0.15.6 |
| --- | --- |
| 지역은 바다로 나뉜 섬들이고, 기계로 날아서 건널 수도 있다 | 로터가 조종 중 상승·고도 유지·하강·전진을 한다. 0.1 m 판의 최소 회전익(약 86 kg, 배터리 2)이 약 12 m/s로 약 200 m를 날아, 지역 사이 바다 160 m를 건널 수 있다 |
| 화면과 조작 감각의 기준은 개척 원정 | 물체 잡기(최대 3500 N, 중력 보정, 잡은 거리 유지, 8 m에서 놓침)·던지기(min(5, 1100÷질량) m/s)·운반 무게(최대 45%까지 느려짐)와 내리기 자리를 개척 원정 규칙으로 |

## 바뀐 것

- `machines.js`
  - `ROTOR_FLIGHT`(1 EU/s당 50 N, 상승·하강 3 m/s, 전진 30%, 공기 감쇠 0.35, 조종 뒤 0.25초).
  - 로터는 조종 입력이 이어지는 동안 동력을 다 쓰고, 상승·하강 입력이 정한 수직 속도를 지키도록 든다(능력 한도).
  - 로터 힘은 설치한 모든 로터의 가운데에서 떨어진 만큼 비켜 무게 중심에 놓는다. 고른 로터는 기울이지 않고 멈춘 로터는 기울인다.
  - 수평 유지 토크, 좌우 회전 토크, 진행 방향 밀기를 더했다.
  - 물리 다리에는 점마다 힘(`forces`)으로 넘긴다(무게 중심 + 로터마다). 날개·승강타 힘은 무게 중심 몫에 그대로 들어간다.
  - 예전 로터 식(면적 = 격자²의 운동량 원판, 전진 입력 크기에 비례)은 없앴다. 제동은 로터를 끄지 않는다.
- `runtime.js` `leaveMachine`: 개척 원정 내리기(옆 네 방향 중 땅이 2 m 넘게 높지 않고 설 자리가 있는 첫 곳, 아니면 2.5 m 위, 기계 수직 속도 이어받기). `game.js`는 이것을 부른다.
- `object-physics.js`: 개척 원정 손 잡기 용수철, 던지기 속도, 잡은 동안 마찰 0.35, `speedScale`. `game.js`가 이동 속도에 곱한다.

## 성능 측정

물리 다리(기계 힘, 물체 잡기)를 바꿔 0.15.5와 같은 도구로 섬·콘텐츠 탐험 장면을 차례로 쟀다([측정](0.15.6-perf.json)). Chromium SwiftShader 수치이며 실기기 수치가 아니다.

| 장면 | 게임 JS 0.15.5 | 게임 JS 0.15.6 | 물리 단계 0.15.5 | 물리 단계 0.15.6 |
| --- | --- | --- | --- | --- |
| 섬 대기 | 14.8 ms | 14.4 ms | 2.70 ms | 2.34 ms |
| 섬 걷기 | 15.2 ms | 16.5 ms | 2.53 ms | 2.68 ms |
| 나무 채굴 1·2·3 | 10.2 · 7.7 · 7.0 ms | 12.3 · 8.9 · 9.5 ms | 1.58 · 1.45 · 1.37 ms | 1.86 · 1.71 · 1.89 ms |
| 분리된 나무 옆 | 8.7 ms | 8.7 ms | 1.36 ms | 1.86 ms |
| 분리된 나무 옆 걷기 | 8.3 ms | 10.3 ms | 1.44 ms | 2.32 ms |
| 콘텐츠 탐험 대기 | 14.5 ms | 14.9 ms | 1.88 ms | 2.32 ms |
| 콘텐츠 탐험 걷기 | 16.3 ms | 17.2 ms | 2.14 ms | 2.63 ms |

같은 0.15.5 빌드를 약 한 시간 전(0.15.5 기록)과 이번에 쟀을 때 게임 JS가 장면마다 0.7~4.2 ms, 물리 단계가 0.1~1.3 ms 달랐다(측정 파일의 `baselineEarlierRun`). 위 차이는 그 범위 안이다. 이 장면들에는 날거나 들고 있는 물체가 없어, 프레임마다 더해진 일은 운반 배율 읽기 한 번과 로터 없는 기계의 빈 목록뿐이다.

## 한계

- 프로펠러·날개는 아직 예전 식이라 비행에 쓰기 어렵다. 형상 항력·바퀴 접지·비행 계기판은 없다(S3에서 기계 시험장과 함께).
- 배터리 망은 연결되어 있으면 쓰지 않아도 출력이 흘러 줄어드는 기존 규칙이라, 회전익의 비행 시간은 배터리 수와 관계없이 약 20초다.
- 운반 집게(강한 잡기)·렌치 고정·블록 붙이기·충돌 파손은 S2c3다.
- 화면에서 실제로 날아 바다를 건너는 장면은 브라우저로 확인하지 않았다(물리 테스트와 직접 실행으로 확인).
