# 0.9.1 — 복셀 캐릭터 검증

2026-10-17. Linux / Node / Chromium + SwiftShader. 게임 901 / 앱·최소 앱 303 / 저장 스키마 2.

## 자동 검사

- `node --test tests/*.test.js`: **123/123**. 신규 검사는 관절 연결·발 접지·동작 초기화·공유 지오메트리의 독립 자세, 뿔의 실제 레이 타격→소유 셀 파괴→장식 제거→저장 복원, 모든 종의 부위별 디테일 제거, 3,200개체의 GPU 인스턴스 버퍼 상한을 포함한다.
- `node tests/character-art-check.cjs`: 실제 터치 드래그로 3D 초상 회전, 취소, 6개 자세 선택과 44px 버튼, 가방↔상태창의 단일 미리보기 재사용, 360×740 세로 화면, 갑옷·선택 도구·빈 손·1인칭 손 연동 통과. 실제 NPC 메시를 조준하여 주민 세 직업의 대화창을 열었다. 같은 틱의 조준 재검사가 걷기 자세를 지우지 않는 것도 확인했다.
- `node tests/content-interactions-check.cjs`: 지속 채굴 손상, 채집 4종, 주민 의뢰/교역, 지형에 가린 대상 사용 차단, 유적과 중계기, 동물 관찰·먹이·치료, 저장 재실행 통과.
- `node tests/structural-check.cjs`: 월드 기계 조립·모바일 사용·자원 차감·주행·저장 및 다리 손상 동물 행동 통과.
- `node tests/menu-reachability-check.cjs`: 900×412, 640×360, 568×320, 360×640, 320×480에서 제작법 50개 노출·실제 좌표 탭, 스와이프 후 제작·슬롯 이동·보관품 받기, 설정·상태·기계 설명·편집·월드 관리 통과. 새 미리보기의 가로 드래그와 가방 세로 스크롤을 분리했다. 자세 선택은 얼굴을 가리지 않도록 모델 아래의 별도 행에 배치했다.
- `node tests/world-ui-check.cjs`: 원근·추적·지형 위 표시, 상태창·소모품·가방의 실제 화면 접근 회귀 검사.

브라우저 검사 결과·빌드 로그는 `0.9.1/`에 보관한다. 기본 URL은 `http://127.0.0.1:8080`, Chromium 경로는 `FERAL_CHROME`으로 지정할 수 있다. 서버는 `npm run serve`로 연다. 기존 메뉴 검사에서 file URL을 사용하는 환경은 HTTP 이동 보조 설정을 적용했다.

인물·동물 비교 화면은 게임에서 사용하는 모델/재질을 별도 고정 조명 장면에 배치한 근접 검증이다. UI와 1인칭 사진은 실제 플레이 장면이다. 인물 4개와 바닥의 자세 비교 장면은 렌더 호출 77회·삼각형 2,642개, 동물 3개 장면은 기본 셀 168개·추가 디테일 200개 인스턴스였다. 이는 전체 게임의 FPS 측정값이 아니다. 페이지·셰이더 오류는 없었다.

## 빌드와 범위

`bash build-apk.sh`, `python3 tools/build-update.py` 통과. APK v2/v3 서명 확인. 업데이트는 새 캐릭터·동물 모듈 5개를 포함한 58개 검증 파일이다. 앱 0.3.3에서 게임 업데이트로 적용하며 기존 저장 형식과 시험 서명 키를 유지한다.

주인공 전신은 3D 가방·상태창에 표시하고 플레이는 계속 1인칭이다. 미리보기 자세는 실제 이동 입력을 바꾸지 않는다. 동물 디테일은 기존 손상 셀에 귀속되며 장식마다 별도 체력을 추가하지 않았다. 실제 Android 기기의 장시간 프레임 안정성·발열·메모리 평가는 수행하지 않았다. 공개 릴리스 및 stable/카탈로그 확인은 병합 후 별도로 수행한다.
