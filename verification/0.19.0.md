# 0.19.0 네이티브 전환 검증

2026-11-08 작업 기록. 게임 0.19.0 / 앱 0.4.0. 최종 네이티브 통합 검사는 통과했으며 APK 포장·공개 게시 검증은 진행 중이다. 공개 배포 완료와 구분한다.

## 실제 실행 범위

Godot 4.6.3, C++17 GDExtension, 단일 Jolt 물리 공간, Compatibility 렌더러를 사용한다. Linux x86_64와 Android arm64의 debug/release 네 가지 대상이 컴파일됐다. 최종 C++ 소스 스냅샷 `4ffd17085c5f97c126aeefc7b43ba1325b5bb0204c17c949063a6409324ab8ce`의 네 가지 대상과 통합 검사가 모두 통과했다. C++ 공유 라이브러리의 동적 공개 심볼은 `feral_library_init` 하나다. Godot와 확장 라이브러리 사이의 표준 라이브러리 심볼 충돌을 막도록 숨김/링커 맵을 적용하고 자동 검사한다.

## 비용 측정의 의미

Gameplay만 측정한 최적화 빌드 600단계에서 유휴 평균 0.96ms, 설비 에너지 제작 중 평균 1.86ms였다. 불변 제작/에너지 목록 캐시 전의 제작 평균 4.67ms보다 줄었다. 이 수치는 전체 프레임이나 물리 엔진 시간, 휴대폰 FPS가 아니다.

전체 World/Gameplay/Simulation/Jolt 실행에서 정지한 나무 → 실제 세 나무 분리 → 안정화의 600단계를 통과했다. 세 나무가 보존된 채 모두 수면 상태에 도달했고, 지형은 676구역으로 유지됐다. 지형 구역 추가·제거 및 안정화 후 메시 재생성은 각각 0회다. 세 나무 분리 계산 합계는 21.683ms였다. 결과는 [네이티브 실행 보고서](0.19.0-native-runtime.json)에 있다.

| 단계 | 콜백 평균 | p95 | 최대 |
| --- | --- | --- | --- |
| 나무가 서 있음 | 3.323ms | 3.988ms | 5.956ms |
| 나무 세 개 분리 후 | 3.792ms | 4.710ms | 25.315ms |
| 안정화 후 | 3.637ms | 4.894ms | 8.451ms |

데스크톱 headless 실행에서 측정한 `FeralGame` 물리 콜백 CPU 시간이다. 콜백 밖에서 수행되는 Jolt 풀이·GPU 시간은 포함하지 않으며 전체 프레임 시간이나 휴대폰 FPS가 아니다. 분리 직후 순간 최대값도 평균과 함께 공개한다.

네이티브 통합 중 확인한 비용 원인은 돌 칸 조회마다 캐시된 광맥 맵 전체를 값으로 복사하던 코드, 지형 열/나무 배치의 반복 계산·JSON 복사, 정지한 플레이어의 미세한 위치 변화로 4m 경계에서 지형 범위가 번갈아 바뀌던 현상이다. 참조 조회와 수명이 보장된 열 캐시, 나무 배치 캐시, 0.25m 범위 전환 여유로 수정했다. 이전 JS의 비충돌 잎 파편이 지하 충돌 지형을 계속 생성하던 버그(0.18.2 수정)와 구분한다.

## 아직 확인하지 않은 환경

Android 실기기에서 설치·기존 앱의 실제 WebView 추출·절전/복귀·터치 감각·GPU FPS·발열은 확인하지 않았다. 데스크톱 소프트웨어 렌더링이나 APK 생성으로 대신 통과했다고 표현하지 않는다. 기존 UI 배치는 원본에 보존하지만 새 Control 화면에 그대로 적용하지 않는다. C++ 코드 업데이트에는 APK 설치가 필요하며 이전 WebView 빌드 선택기로 네이티브 코드를 교체하지 않는다.
