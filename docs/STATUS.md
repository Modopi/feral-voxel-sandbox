## 지금의 구조 (요약)

0.15.0부터 앱을 켜면 게임 밖 **런처**가 나온다. 런처에서 월드를 고르거나(이어하기 포함) 새로 만들고, 월드마다 설정(생존·샌드박스·시작 건축물·시작 소지품·사망 시 소지품 남김 중 그 맵이 지원하는 것)을 만들거나 고치고, 전역 설정과 업데이트를 본다. 월드에 들어가면 게임 세션이 그 월드 설정대로 시작되고, 메뉴의 "저장 후 런처로"로 돌아온다. 게임 버전을 바꿔도 저장 보관함이 최신 월드와 저장을 되살린다(0.14.1 이하에서 0.15.0으로 올 때는 "지금 확인 → 저장 후 적용"으로 받아야 한다). 게임 세션 안에는 아직 엔진이 세 개 있으며 세션 라우터 한 곳이 고른다. 남은 구조 문제는 [구조 문서](ARCHITECTURE.md#알려진-구조-문제-현재), 고치는 순서는 [로드맵](ROADMAP.md)에 있다.

| 프리셋 | 엔진 | 되는 것 |
| --- | --- | --- |
| 기본 섬 | 통합 런타임 | 원본과 같은 160×160 m 섬, 같은 세 종의 생태, 평화 규칙(설정에서 생존으로 바꿀 수 있음), 샌드박스 도구·블록 쌓기, 다섯 장소·미니맵, 연구·제작. 기존 섬 저장은 원본을 보존한 채 변환 |
| 콘텐츠 탐험 | 통합 런타임 | 무한 청크, 설계 생명체·던전·보스, 연구·제작·설비·기계·에너지·신앙·공동체, 사망 회수(설정 "사망 시 소지품 남김"을 끄면 소지품을 지닌 채 깨어남, 0.15.3부터), 낙하·물체 충돌 피해(0.15.5부터), 로터 비행과 개척 원정식 물체 잡기(0.15.6부터), 렌치·집게·블록 붙이기(0.15.7부터), 물체·기계의 충돌 파손(0.15.8부터). 설정에서 생존을 끄면 평화 규칙, 샌드박스를 켜면 섬과 같은 샌드박스 도구·블록 쌓기(생태는 그 자리 환경의 종, 0.15.2부터) |
| 개척 원정 | 통합 런타임(0.16.0부터) | 첫 신호 캠페인(`first-signal` 모듈: 여정·야영지·신호망·원정, 마을 교역·의뢰·외교, 유적 중계기, 수호자), 바다로 나뉜 지역 섬과 지역 이동, 시작 보급, 기존 개척 원정 저장 변환, 통합 런타임의 기계·물체·충격 규칙 |
| 기계 시험장 | 옛 엔진(`machine.html`) | 7×3×7 격자 조립·주행 시험. 자체 화면. 런처의 같은 입구로 들어감 |

두 통합 런타임 월드는 개척 원정 기준의 감각을 쓴다: 즉시 채집, 개척 원정 채굴 공식, 분리된 덩어리 깎기, 외피가 깎이고 골격이 드러나는 생명체, 든 것이 정하는 타격 방식([게임 규칙](GAME-RULES.md)).

## 알려진 한계

- Android 실기기 검증이 부족하다. 0.12.1 이후의 시작·업데이트·터치·성능은 데스크톱 브라우저(SwiftShader)와 앱 규칙 서버로만 확인했다.
- 성능: 0.15.1에서 프레임 구조를 고쳤다(바뀐 4m 구역만 다시 만들기, 프레임 예산, 생물 AI 분산, [구조 7장](ARCHITECTURE.md#7-성능-구조-현재-0151부터)). 나무를 캐 분리된 덩어리가 생긴 뒤 프레임 루프 JS 시간이 0.15.0의 92~131ms에서 8~9ms로 줄었다(SwiftShader 측정, [0.15.1 검증](../verification/0.15.1.md)). 실기기 수치는 아직 없고, 콘텐츠 탐험은 첫 로딩 뒤 주변 지형을 다 채우는 데 약 30초가 걸린다(지형 생성의 웹 워커 이전은 [로드맵](ROADMAP.md) P2).
- 검사는 필수 회귀(`npm test`, 약 20초)와 바꾼 영역만 도는 장기 검사(`tests/long/`)로 나눴다. 0.12.1부터 같은 위치·값으로 실패하던 예전 화면 검사 5개(survival-ui·frontier·world-ui·layered-body·aerodynamics-movement)와 기존 섬 엔진 전용 기록 2개(browser·progression)는 지웠다. 남은 예전 화면 검사 12개는 옛 엔진을 통합하며 없앤다.
- 유체는 1 m 셀이라 반 칸 틈을 정밀하게 흐르지 않는다. 공기역학·충격·부력은 게임용 근사 모델이다.
- 조준 대상 카드가 가까운 대상을 내려다볼 때 오른쪽 위 버튼과 겹칠 수 있다(0.13.0부터).

## 콘텐츠 쪽 남은 과제

구조 단계([로드맵](ROADMAP.md))와 별개인 [구현 Goal](IMPLEMENTATION-GOAL.md)의 남은 과제다. 제안이며 확정 일정이 아니다.

| 과제 | 완료를 판단할 증거 |
| --- | --- |
| 새 콘텐츠 탐험 월드에서 정상 입력만으로 보스까지 진행 | 자원 지급 없이 채집→연구→제작→장비·기계→던전·보스의 브라우저 완주 기록 |
| 실제 Android에서 설치·업데이트·장시간 플레이 | 기기·OS/WebView, 30분·2시간 세션 프레임, 메모리, 열 제한, 백그라운드 복귀·프로세스 종료 후 저장 복원 |
| 무한 월드의 장거리 메모리 상한 | 방문 이력·보존 개체의 분할 저장 또는 상한 정책과 장거리 왕복 측정 |
| 나머지 던전 장치 7종과 보스 회피의 화면 완주 | 장치별 실제 조작·보상·저장 재개 |
| 실물 설비 배선·기계 주행, 에너지→재질 반응의 전투 연결 | 실제 배치·연결·충전·주행과 채널별 피해·물성 변화 |
