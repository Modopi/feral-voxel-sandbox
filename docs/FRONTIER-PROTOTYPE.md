# 0.4.0 개척 원정 프로토타입

장기기획의 탐험 → 자원 획득 → 개인/기계/공동체 성장 → 수호자 → 다음 지역 순환을 실제 플레이로 연결하는 첫 구현이다. 장기기획 전체의 완성 선언이 아니며 아직 배포하지 않은 개발 버전이다.

## 시작과 진행

월드 선택에서 **개척 원정**을 플레이한다. 이미 월드 목록을 만든 사용자는 유형 **개척 원정 · 전체 게임 프로토타입**으로 새 월드를 만들면 된다. 기존 기본 섬과 기계 시험장 저장은 그대로 유지된다.

1. 출발 야영지에서 목표 화살표와 목재 보급로를 따라 강변 야영지로 이동한다.
2. 마을 12m 안에서 **상호작용 / R** → 교역. 원목 4개로 결정 2개와 식량 2개를 얻는다. 가방에서 원목을 목재로 가공한다.
3. 마을에 식량 3·목재 4를 지원하면 연구 기록 2와 평판 12를 얻는다. 평판 24부터 동맹 가능. 교역도 평판을 올린다.
4. 가방의 현장 제작에서 합금·무기·갑옷·회복약을 만들거나 동력 연구를 한다. 장소 발견·유적 탐사·마을 지원으로 연구가 가능하며 보스 선행 조건은 없다.
5. 유적 중심에서는 방어장 피해를 견디며 약 18초 동안 해제한다. 상호작용으로 보상을 회수한다. 회복약은 장부에서 사용하거나 H를 누른다.
6. 펄스 도구로 수호자를 조준·공격한다. 붉은 원이 나타나면 1.15초 안에 원 밖으로 피한다. 동맹은 근처 전투에 지원한다. 수호자 보상은 지역당 한 번 지급된다.
7. 야영지 또는 지역 가장자리에서 **장부 / J → 지역·목표**를 열어 인접 지역으로 이동한다. 식량 1개를 소비하고 지역을 새로 로드한다. 멀리 갈수록 위험이 1~3으로 증가한다.

식량은 이동과 포만 유지에 쓰인다. 식물 섬유·씨앗으로 제작하거나 마을에서 교역한다. 포만이 바닥나면 체력이 감소한다. 사망하면 소지품과 기계를 유지한 채 경험 15를 잃고 야영지로 돌아간다.

## 제작과 기계

- 동력 연구 후 기본 차량 설계를 제작하면 차체·모터·바퀴로 구성된 차량 1대를 얻는다. 이미 얻은 차량은 메뉴 재진입으로 재지급되지 않는다.
- **장부 → 기계**에서 7×3×7, 한 칸 0.5m 격자를 편집한다. 야영지에서 하차 상태로 배치·제거·수리하며 가방의 합금을 사용한다.
- 원점 차체에 면으로 연결된 부품만 작동한다. 손상된 모터·바퀴·회전익·포탑의 성능은 남은 HP에 비례한다. 파괴된 부품의 설계는 남아 수리 가능하다.
- 투사체 연구 후 포탑을 배치하면 탑승 상태의 펄스 공격이 돌 조각 1개를 소비하는 포격으로 바뀐다. 다중 포탑도 연결 상태와 HP를 반영한다.
- 회전익 연구 후 연결된 회전익 2개를 배치하면 탑승 후 **F / 비행 버튼**으로 간이 비행한다. 점프/상승 키와 시선 방향을 사용하며 Q로 하강한다.
- 기계 손상은 충돌과 탑승 중 피격으로 발생한다. 수리·해체 자원은 현재 손상을 반영해 증식하지 않는다.
- 주행은 기존 지형 충돌 컨트롤러에 출력/질량·접지 비율을 적용한 운동학적 프로토타입이다. 별도 시험장의 60Hz 평면 역학은 유지된다. 3D 강체, 서스펜션, 전복, 공기역학, 궤도·고정익 비행기를 구현했다는 뜻은 아니다.

## 공동체와 사회

각 지역에는 두 마을이 있으며 이끼 연맹·구리 조합·현무암 부족에 속한다. 마을은 식량·원목·돌·결정 재고와 인구·기술·지원 기록을 보유한다. 활성 플레이 시간 30초마다 방문한 모든 지역의 마을이 생산·소비한다. 다른 지역의 마을에도 동일한 거시 규칙을 적용한다. 보조금 없이 기술 1까지 천천히 발전하며 플레이어 지원으로 기술 2까지 가속할 수 있다.

교역은 실제 재고를 소비한다. 지원은 기술·평판·연구를, 동맹은 전투 지원을 제공한다. 약탈은 확인 후 실행되며 평판 하락·동맹 해제·경비 피해·교역 중단을 유발한다. 화해에는 식량과 합금이 필요하다. 집단 관계는 주기적으로 변하며 분쟁은 재고에 피해를 주고 중재는 관계를 회복한다.

주민의 현장 이동은 단순한 순찰 표현이다. 개인별 생산 AI, 경로 탐색, 실제 보급 수송, 영토 전쟁·군단 지휘는 후속 범위다. 동맹 전투 지원도 지원병 표시와 주기적 피해로 단순화했다. 앱 종료·일시정지 중에는 시간이 진행되지 않는다.

## 월드와 저장

- 시드와 지역 좌표로 지형을 재현한다. 160×160m 지역마다 마을·유적·수호자 거점을 배치한다. 주요 거점에 접근 가능한 보급로를 만든다.
- 지역 좌표는 프로토타입에서 각 축 ±10,000으로 제한한다. 무중단 무한 청크 스트리밍은 아니다. 지역 이동 때 페이지를 재시작해 렌더·메모리를 정리한다.
- 저장 스키마 2에 선택 필드 `campaign`(하위 스키마 1)과 `regionCache`를 추가했다. 기존 섬의 스키마 1/2 로드는 유지한다.
- 현재 지역은 원래 저장의 지형·생태·드롭을 사용하고, 이전 지역은 동일한 스냅샷을 보관한다. 소지품·연구·관계·기계·수호자 보상은 원정 전체에서 공유한다.
- 지역 이동은 출발 스냅샷·도착 상태·식량 소비를 한 저장에 기록한 다음에만 전환한다. 저장 공간 오류는 이동과 식량 소비를 취소한다. 종료 자동 저장이 도착 저장을 덮어쓰지 않도록 전환 시 기존 실행을 정지한다.
- 브라우저/WebView 저장 용량 내에서 방문 지역을 보존한다. 자동으로 과거 지역을 삭제하지 않으므로 장기 탐험 시 저장 공간이 한계가 된다. 대규모 월드용 IndexedDB/파일 저장·압축은 후속 작업이다.
- 먼 지역의 **공동체 상태**는 진행하지만 상세 생태·유체는 스냅샷으로 중지된다. 새로 방문하기 전의 지역은 시뮬레이션하지 않는다.

## 책임 경계

| 파일 | 책임 |
| --- | --- |
| `frontier/model.js` | 지역·성장·거래·외교·보스·보상·기계 자원 규칙 및 저장 검증 |
| `frontier/terrain.js` | 결정적 지형·거점·보급로 생성 |
| `frontier/motion.js` | 추상 이동 명령 → 기계 출력/질량·지형 충돌·손상 |
| `frontier/view.js` | DOM/Three.js 표현, 조준 판정, 입력 전달 |
| `main.js` | 기존 탐험 기능과 시간 진행·저장·지역 전환 연결 |

## 남은 장기 목표

정교한 무한 월드·도시·절차적 던전 내부, 독립 NPC 계획 AI와 경제·전쟁, 기계의 실제 3D 역학·복셀 절단/분리·고정익 비행, 대규모 저장과 장시간 성능 최적화는 아직 구현하지 않았다. 현재 보스는 단계별 능력치와 예고 공격을 가진 단순 전투이고, 유적은 방어장 해제형 탐사다. 기존 생태 몹의 복셀 부위 손상은 그대로 유지한다.

## 검증

- 순수 모델·기존 회귀 테스트: `node --test tests/*.test.js`.
- 개척 통합: HTTP 서버 실행 후 `node tests/frontier-check.cjs`.
- 기존 섬: `tests/progression-check.cjs`; 기존 기계·월드 목록: `tests/machine-check.cjs`.
- APK: `bash build-apk.sh`; 서명 업데이트: `python3 tools/build-update.py`.

실제 Android 기기의 장시간 플레이·발열·터치감·저장 한계는 별도 확인이 필요하다.
