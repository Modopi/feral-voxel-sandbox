# FERAL 콘텐츠·성장 통합 설계

작성: 2026-10-17. 상태: **사용자 확정 원칙 + 콘텐츠 구현 제안**. 구현 완료 명세나 배포 일정이 아니다.

후속 산출물: [상세 콘텐츠 위키](content/README.md). 환경·블록·34종 생명체·12개 건축물·8보스·재료/연구/제작의 변수 사전과 JSON 데이터 및 [통합 검증](content/INTEGRATION.md)을 제공한다.

이 문서는 게임 비전의 후속 설계다. 아래의 ‘확정’은 사용자 결정이며, 환경·던전·보스 이름, 구체적 제작 경로와 구현 방식은 모두 ‘제안’이다. 제안의 채택을 사용자 결정으로 소급하지 않는다. 게임 버전은 변경하지 않는다.

## 1. 확정된 제품 원칙

- 탐험과 성장이 핵심 진행이다. 생활과 공동체는 거점의 생산·보급·회복을 통해 이를 보조한다.
- 물리와 제작은 기반이다. 제작 결과에는 개인 장비와 자유롭게 구성한 기계 구조물이 모두 포함된다. 전차·헬기·움직이는 성·우주선은 장기 제작 목표의 예다.
- 플레이어가 만든 구조물은 반드시 기계 엔티티다. 자율 제어 여부로 무기생명으로 바뀌지 않는다. 유기·무기생명 제작은 먼 후속 범위다.
- 사물 엔티티는 월드에서 파손·분리된 물체다. 유기생명은 칼로리와 자연회복을, 무기생명은 칼로리 없는 수리 회복과 상대적으로 높은 HP·능력치를 가진다.
- 유기·무기생명의 문명 속성이 켜져 있으면 플레이어와 상호작용 가능한 공동체를 형성한다. 꺼져 있으면 집단도 야생 무리 수준이다. 공동체 값은 개체와 별도로 관리한다.
- 유기생명은 HP가 부족하고 일정 시간 피격받지 않았거나 휴식 중이면 칼로리를 소모해 HP를 회복한다. 소모·회복량은 개체별로 다를 수 있다.
- 탐험의 주된 발견물은 건축물이다. 기본 환경에는 포식자·피식자와 먹이사슬이 있고, 던전은 주변과 어울리면서도 어느 정도 격리된 폐쇄 생태계 및 보스를 가진다. 공동체·유적도 환경에 맞게 배치한다.
- 장기 목표는 무한 월드다. 최초 스폰이 기본 리스폰이자 거리 난도의 중심이다. 멀어질수록 어려워지며 월드 평균 난도는 5~6티어를 지향한다. 더 높은 난도는 먼 동서남북에 파편처럼 분산하여 우회할 수 있어야 한다.
- 모든 기술·제작법은 자체 연구로 열 수 있다. 연구만으로는 오래 걸리고, 유적의 연구 설계도가 해금을 앞당긴다. 발견으로만 얻을 수 있는 결과물은 두지 않으며 모두 제작 가능하게 한다.
- 기능은 정의된 기능 컴포넌트의 범위 안에서 결정한다. 복셀은 외형·재질·구조·내구도·상호작용 물성을 결정하며 기능 성능에도 영향을 준다. 플레이어는 이러한 기능 단위 컴포넌트를 조립한다. 이 원칙은 기존 GAME-VISION의 5절에도 명시돼 있다.
- 네 계열은 자유롭게 혼합하는 연구·제작 분야다. 초기의 자원 부족 때문에 한 분야가 앞서고 다른 분야는 느리지만, 충분히 성장하면 모두 열 수 있다. 직업 선택에 따른 영구 잠금은 없다.
- 사망 시 소지 아이템 전부를 사망 위치에 남긴다. 아이템은 소멸하지 않으며 근방 10m에 접근하면 요정이 가져와 회수할 수 있게 한다. 배치한 기계의 손실 규칙은 이 결정에 포함하지 않는다.

## 2. 기존 구현과의 차이

로컬 기준 게임 0.10.0에는 지역 전환형 개척 원정, 이끼 숲·붉은 구릉·유리 해안, 첫 신호 캠페인, 주민 의뢰·교역·야영지, 구조 손상·분리 물체·조립 차량이 있다. 무한 월드, 여기서 정의하는 전 재료 티어, 일반화된 여섯 에너지망, 폐쇄 던전 생태계가 완성된 상태는 아니다.

기존 FIRST-SIGNAL은 구현된 캠페인의 기록으로 보존한다. 세 신호 복원을 새 전체 성장의 필수 관문으로 확대하지 않는다. 기존 자원 순환·획득 경로 검사는 새 연구·제작망의 검증 기반으로 활용한다. 기존 `iron` 등의 식별자를 새 재료에 이름만으로 대응시키지 않고 실제 의미와 저장 호환을 확인한다.

## 3. 월드 배치 제안

### 거리 난도와 지역 특성의 분리

월드 생성은 환경, 난도, 건축물 배치를 서로 다른 단계로 계산한다. 숲이라는 이유만으로 저티어가 되거나 특정 방향이 특정 연구 계열 전용이 되지 않는다.

1. 시드와 절대 월드 좌표로 기본 지형·기후·환경을 생성한다.
2. 최초 스폰과의 거리로 기본 난도를 계산한다. 초기 저티어권을 지나 5~6티어 부근에 수렴시키는 곡선을 제안한다.
3. 먼 네 방향에 제한된 크기의 7~10티어 고난도 지역을 생성한다. 연속적인 고난도 고리나 대륙 전체를 막는 장벽이 되지 않게 한다.
4. 환경과 난도에 맞는 던전·공동체·유적을 배치한다. 모든 건축물이 던전인 것은 아니다.
5. 건축물 주변의 접근·우회 경로를 검사하고, 필수 경로를 막는 배치는 다시 생성한다.

무한 전체의 산술 평균을 직접 계산할 수 없으므로, 5~6티어 평균 목표는 거리 구간별 면적 가중 표본으로 검증한다. 표본 범위·허용 편차·고난도 점유율은 시뮬레이션 후 설정할 값이다. 초기 보호권과 10티어 도달 거리를 임의의 확정 수치로 두지 않는다.

표의 생태는 제안된 게임 규칙이다. 무기생명 경비가 있는 던전도 별도 생물 먹이망을 가질 수 있으며, 로봇을 먹이사슬에 억지로 넣지 않는다. 각 던전은 내부 생산원·소비자·포식자·영역·개체수 회복 조건을 가지며, 단순 적 생성 목록으로 대체하지 않는다.

던전의 자원·설계도는 유리한 획득 경로이지 독점 경로가 아니다. 제작법마다 야외 원료·가공·연구를 통한 경로를 함께 제공한다. 원정 선택은 환경 유형과 현재 난도 둘 다 보고 결정한다.

| 성자 | 신성 획득 활동, 축성, 성물 생산·저장 | 원시 마정석 합성→정제→성철 가공→축복→성자의 인내 구현 | 성물의 축적, 높은 강화 성능의 재료·장비 |
| 물리학자 | 역학 저장·제어, 특수 물질 가공 | 관성합금→알파입자 취급→중성미자 응집→초끈집합체 구성→우주 거대 구조 구현 | 운동 제어·고위 에너지 저장·장거리 이동 구조물 |

이 표는 게임 내 가상 공정의 방향이다. 구체적 배합이나 현실 물리 공정이 아니다. 아다만티늄은 사용자 재료표에서 독립 티어가 정해지지 않았으므로 여기서는 7티어 제작의 중간 가공 단계 후보로만 다룬다. 상위 재료의 실물 형태·제작 단위·저장 방식은 별도 명세가 필요하다.

계열 간 교차 투자는 허용한다. 7티어 축성을 위해 반드시 성자 7티어까지 진행해야 한다고 임의로 정하지 않는다. 축성의 기초 접근과 성자 계열의 고위 특화를 구분하고, 모든 계열의 필수 선행 연구가 순환하지 않도록 검증한다.

에너지는 저장량·출력·전달·변환 효율을 구분하는 설계를 제안한다. 전투 피해는 방출량, 전달 방식, 대상 재질·구조 반응을 거쳐 산출한다. 별도 전투용 수치가 에너지 소비 없이 무한히 발생하지 않게 한다.

## 6. 연구·보상 규칙 제안

각 연구에 선행 지식, 자체 연구 재료·설비·진행량, 해금 결과, 연결된 유적 설계도를 기록한다. 연구 진행은 실험·가공·관찰을 통해 축적할 수 있게 하고, 단순 대기만으로 모든 과정을 대체할지는 아직 정하지 않는다.

- 자체 연구 경로는 발견 전용 아이템을 요구하지 않는다.
- 설계도 발견으로 지식을 얻어도 실제 제작의 재료·설비 비용은 남는 방식을 제안한다.
- 같은 설계도 재발견은 연구 자료나 다른 유효 보상으로 바꾸어 탐험 보상의 의미를 유지한다.
- 유적·보스 보상은 희귀 재료의 빠른 확보, 연구 해금, 사용자 규칙에 따른 신성 획득 등으로 구성한다.
- 던전에서 완성품을 얻을 수 있어도 같은 결과물의 자체 제작 경로가 존재해야 한다.
- 성물 제작에 필요한 첫 신성은 사용자 설정의 퀘스트·기여·보스·시련 경로로 얻는다. 성물이 있어야 첫 성물을 만들 수 있는 순환을 만들지 않는다.

## 7. 처음 완성할 플레이 구간 제안

초반 시험 구간은 숲·구릉, 저택·채굴 요새, 생산·정비 공동체로 구성한다. 전체 티어의 제작 규칙을 수용하는 구조로 만들되 콘텐츠는 1~3티어부터 연결한다.

1. 기본 환경에서 식량·목재·돌을 얻고 도구와 거점 작업 공간을 마련한다.
2. 외부 먹이사슬과 다른 내부 생태가 있는 저택을 발견한다. 생태·지형·재료를 이용해 탐색한다.
3. 유적 설계도로 연구를 앞당기거나, 거점에서 동일 지식을 자체 연구한다.
4. 정의된 접합·운반 기능과 복셀 구성으로 운반 구조물을 만든다. 초기 단계에서 동력 구동을 필수로 요구하지 않는다.
5. 구릉의 광산·채굴 요새에서 잡철 원료를 확보하여 장비와 구조물을 개선한다. 보스 보상 없이도 같은 성장 단계에 도달하는 경로를 제공한다.
6. 고난도 구역을 만났을 때 주변 경로로 우회하여 계속 탐험할 수 있다.
7. 사망 시 아이템이 보존되고, 재접근하면 요정이 회수를 돕는다.

완료 기준은 ‘한 번 보스를 잡았다’가 아니라 두 성장 경로(탐험 해금/자체 연구), 제작물의 실제 활용, 귀환·보급, 사망 회수까지 플레이가 이어지는 것이다. 정해진 플레이 시간은 측정 전 약속하지 않는다.

## 8. 개발 순서와 검증

| 단계 | 구현 묶음 | 완료 판정 |
|---|---|---|
| A | 콘텐츠 정의·재료·연구·기능 계약과 저장 버전 설계 | 모든 해금 결과에 자체 연구·제작 경로가 있고 선행 관계에 막힌 순환이 없음 |
| B | 절대 좌표·최초 스폰·지역 식별·난도 생성 및 영속 상태 | 방문 순서와 재접속에 무관한 생성, 표본 난도와 우회 경로 검증 |
| C | 숲·구릉의 기본 생태와 건축물/던전 두 종류 | 외부·내부 먹이망과 보스·보상이 연결되고 상태가 보존됨 |

| E | 사망 보관·요정 회수와 해당 구간의 모바일 검증 | 여러 사망·재접속·가방 부족·지역 이탈에도 손실/중복 없음, 10m 접근 회수 |

| H | 6~10티어 계열별 생산·복합 제작·고난도 던전 | 계열 혼합과 비독점 획득 유지, 상위 제작물에 실제 탐험 사용처 존재 |

무한 월드의 좌표·저장 계약은 초기에 설계하고, 실제 스트리밍 완료와 소규모 구간 검증을 구별한다. 기존 지역 전환을 무한 월드 완료로 표현하지 않는다. 각 단계는 저장·모바일·기존 기능 회귀를 함께 확인한다.

### 필요한 데이터 계약

- 환경: 생성 조건, 기본 생태, 건축물 후보.
- 던전: 환경 적합성, 구조, 내부 생태, 보스, 연구·재료 보상.
- 재료: 티어·계열·물성, 가공 경로와 제작 용도.
- 연구: 선행 지식·자체 연구 경로·설계도 해금·결과.
- 컴포넌트: 기능 정의·에너지 입출력·복셀 구성의 성능 평가.
- 공동체: 소속 개체·거점·생산·관계·기여도. 문명 속성은 개체에 둠.
- 사망 보관: 소유자·월드 좌표·아이템·수령 상태. 보관과 인벤토리 변경은 중복/손실 없이 처리.

가방 포화 시 미수령분을 보존하고, 여러 사망 보관을 각각 유지하는 방식을 제안한다. 자동 수령 순서와 요정 표현은 후속 UI 설계 사항이다.

## 9. 기존 저장과 문서 정책

기존 월드의 지형·부품·아이템을 새 정의로 임의 덮어쓰지 않는다. 새로운 월드 생성 규칙은 생성 버전으로 구분하고, 기존 월드 지원 또는 새 월드 필요 여부를 마이그레이션 설계 단계에서 명시한다. 원본 저장을 보존하고 이전 실패를 복구할 수 있어야 한다.

실제 코드 변경 시 관련 순수 모델·브라우저 검증, 저장 왕복, APK 빌드와 저장소의 배포 규칙을 적용한다. 이 문서만으로 버전 증가·게임 변경·배포를 수행하지 않는다.

남은 숫자·이름·배합은 이 원칙을 따르는 구현 초안으로 제안한다. 이미 확정된 기능 컴포넌트 분리나 계열 혼합을 다시 미정 항목으로 올리지 않는다.
