# 게임 창과 UI 배치 편집 (0.5.3)

> **보관 문서.** 작성 당시 버전의 설명이며 현재 구조·규칙의 기준이 아니다. 현재 기준은 [소프트웨어 구조](../ARCHITECTURE.md), [현황](../STATUS.md), [게임 규칙](../GAME-RULES.md)이다. 옛 엔진의 기능을 통합 세션으로 옮길 때 동작을 참고하는 용도로만 쓴다.

메뉴 → **UI 배치 편집** 또는 환경 설정 → **UI 배치 편집**에서 연다. 게임은 일시정지하고 플레이 화면 위에 각 요소의 테두리가 나타난다. 창의 **조절** 버튼으로 속성창을 접으면 그 뒤에 있던 스틱도 끌어 옮길 수 있다. 선택 목록으로 요소를 고를 수도 있다.

- 테두리를 드래그해 위치 변경. 키보드 방향키는 2px, Shift+방향키는 10px 이동.
- 크기 65~150%, 불투명도 40~100%. 작은 조작 버튼은 최소 36px를 유지하며 화면을 벗어나지 않게 제한한다.
- 이동·공격·사용·점프·비행·크기 버튼, 가방·메뉴·지도·상태·상호작용, 핫바·생존 수치를 편집한다. 비행/상호작용은 편집할 때 미리 표시되며 플레이에서는 원래 해금·접근 조건을 따른다.
- 아이템 이름·목적지·알림만 숨길 수 있다. 필수 조작과 생존 수치는 숨김을 막는다.
- **선택 복원**은 선택한 요소, **현재 배치 초기화**는 현재 방향·손잡이 배치만 기본값으로 되돌린다. 저장 전에는 취소 가능하다.
- **저장**은 기기에 적용하고 **취소**, Esc, Android 뒤로 가기는 마지막 저장으로 돌아간다. 저장 공간 오류가 나면 편집 화면과 초안을 유지하고 이유를 표시한다.
- 가로/세로 × 오른손/왼손 네 가지 배치를 따로 저장한다. 다른 해상도에서는 화면 가장자리와의 상대 위치를 보존한다. 손잡이 설정은 기존 환경 설정의 왼손 모드에서 바꾼다.
- **게임 창 색상**은 흑요석/사암 중 선택. 메뉴·인벤토리·원정·월드 목록·기계 창에 함께 적용한다.

창은 HTML로 렌더링하는 2D 게임 UI다. 편집기는 플레이 HUD의 위치·크기·투명도와 공통 창 색상을 바꾼다. 내부 인벤토리 슬롯 순서나 제작 레이아웃을 자유롭게 설계하는 개발용 편집기는 아니다. 3D 대상 정보창의 위치는 대상 월드 좌표를 계속 따른다.

## 저장과 입력

`hud-layout.js`가 허용된 요소/값을 검증하고 위치를 계산한다. `hud-editor.js`는 원래 CSS 배치를 기본값으로 사용하며 편집 초안을 별도로 유지한다. `feral.ui.layout.v1`에 저장하여 기존 네이티브의 feral.* 저장 백업·빌드별 저장 격리를 그대로 적용한다. 새/손상된 설정은 기본 배치로 복구한다.

게임 입력은 편집 오버레이에서 막고 포인터 캡처로 화면을 가로질러 이동한다. 시스템의 터치 취소는 드래그 시작 전 위치로 복구한다. 숨김·알림 페이드·일시정지 시 HUD 감춤 같은 원래 표시 조건은 사용자 배치 이후에도 유지한다.

## 지형 편집 단위

기본 지형 블록은 1m이고 실제 채굴·설치의 기본 단위는 **반 칸, 0.5m**다. 새 게임과 과거 저장의 자동 1m 값은 0.5m로 시작한다. 이는 1m 블록을 2×2×2로 나눈 한 셀이며 인벤토리 블록 자원 1개에 해당한다. 1m 설치는 8개를 사용한다.

크기 버튼은 반 칸/한 칸을 전환하고 채굴 해머 해금 후에는 2m 채굴도 고를 수 있다. `editGridVersion: 1`을 저장한 이후에는 고른 크기를 이어하기와 지역 이동에서도 보존한다. 0.25m는 생명체의 세부 복셀 해상도이며 지형 편집에서는 제공하지 않는다. 저장 스키마 2의 선택 필드로 추가되어 월드나 인벤토리를 초기화하지 않는다.
