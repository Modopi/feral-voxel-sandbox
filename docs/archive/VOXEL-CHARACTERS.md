# 0.9.1 캐릭터 아트와 동작

> **보관 문서.** 작성 당시 버전의 설명이며 현재 구조·규칙의 기준이 아니다. 현재 기준은 [소프트웨어 구조](../ARCHITECTURE.md), [현황](../STATUS.md), [게임 규칙](../GAME-RULES.md)이다. 옛 엔진의 기능을 통합 세션으로 옮길 때 동작을 참고하는 용도로만 쓴다.

이번 변경의 중심은 조명이나 HTML 장식이 아니라 실제 엔티티의 형태·표면·관절이다. 사람 모델은 1/32m 모델링 단위를 사용하고 큰 형태에는 넓은 면, 얼굴·봉제선·장비에는 작은 픽셀 군집을 사용한다. 전체를 작은 큐브로 채우지 않고 한 관절의 박스들을 하나의 지오메트리로 합친다. 모델·표면 무늬는 직접 작성했으며 외부 게임의 모델·스킨·애니메이션 파일을 사용하지 않았다.

## 참고 사례와 적용

- [Blockbench Minecraft Style Guide](https://blockbench.net/wiki/guides/minecraft-style-guide/): 일관된 텍셀 밀도, 읽히는 실루엣, 목적이 있는 픽셀 군집과 제한된 팔레트. 천·가죽·머리카락·금속·유리의 표면을 구분하고 의미 없는 전신 무작위 얼룩을 제거했다. FERAL 사람·동물의 표면 기준은 32 texel/m이다.
- [Blockbench Bedrock Modeling](https://blockbench.net/wiki/guides/bedrock-modeling/): 그룹 계층과 피벗으로 관절을 연결하고 실제 상태에 따라 동작을 선택하는 방식. 어깨→팔꿈치→손, 골반→무릎→발목을 연결하고, 주민의 실제 이동 거리가 걸음 위상을 진행시킨다.
- [Minecraft 공식: It Takes a Village — Element Animation](https://www.minecraft.net/en-us/article/it-takes-village): 주민을 성격 있는 대화 상대로 다루는 제작 사례. 역할별 의복·도구, 눈깜박임·입 움직임·고개 끄덕임·손인사로 주민의 반응을 표현했다.
- [Svep: Minecraft Dungeons Cinematic](https://www.svepstudios.se/work/minecraft-dungeons-cinematic): 공식 시네마틱 제작 사례의 캐릭터·행동 중심 연출을 참고했다. 형태를 유지하는 관절 굽힘과 행동별 자세를 적용했다. 영상 전체를 분석하거나 원작 리그를 재현한 작업은 아니다.

플레이는 계속 1인칭이다. 전신 개척자는 가방·상태창의 실제 3D 미리보기에서 보이고, 플레이 화면에는 같은 팔레트·손목·장갑의 팔을 표시한다. 이번에 3인칭 카메라나 플레이어 전신 충돌체를 추가한 것은 아니다. 미리보기의 자세 선택은 캐릭터 구경용이며 실제 이동 자세를 바꾸지 않는다.

## 손상·성능·호환

동물의 저장된 부위 순서·셀 크기·손상 마스크는 유지한다. 장식 하나는 반드시 기존 해부학 셀 하나에 속하며, 넓은 표면 장식은 그 셀 경계에서 나눈다. 뿔·주둥이·꼬리처럼 원래 몸체 밖에 나온 부분도 레이 판정에 포함하고 소유 셀에 피해를 전달한다. 소유 셀이 없어지면 표면도 사라진다. 작은 장식은 독립 체력이나 새 저장 셀을 갖지 않는다.

동물은 기존 두 InstancedMesh를 사용한다. 23m 이내의 디테일 예산에서 작은 무늬를 표시하고, 큰 실루엣 장식은 35m까지 표시한다. 인물은 역할·피부 변형·갑옷별 지오메트리와 재질을 공유하며 먼 거리에는 작은 얼굴 파트를 숨긴다. 가방과 상태창은 WebGL 미리보기 렌더러 한 개를 공유한다. 보이는 동안만 약 12.5fps로 그리며 월드 시뮬레이션은 계속 일시정지된다.

새 저장 필드는 없다. 게임 0.9.1 / 901, 앱·최소 앱 0.3.3 / 303, 저장 스키마 2. 실제 Android 기기의 장시간 GPU·발열 평가는 브라우저 소프트웨어 렌더링 검사와 별개다.
