# 월드 공간 정보창과 게임 창 (0.7.1)

> **보관 문서.** 작성 당시 버전의 설명이며 현재 구조·규칙의 기준이 아니다. 현재 기준은 [소프트웨어 구조](../ARCHITECTURE.md), [현황](../STATUS.md), [게임 규칙](../GAME-RULES.md)이다. 옛 엔진의 기능을 통합 세션으로 옮길 때 동작을 참고하는 용도로만 쓴다.

Unity의 World Space Canvas처럼, 정보창을 월드 좌표에 놓고 게임 카메라로 렌더링한다. CSS로 3D 위치를 화면에 투영해 옮기는 방식이 아니다.

`world-ui.js`의 `WorldUI`는 Three.js 장면 아래에 2.4 × 0.9m 평면과 대상을 잇는 짧은 선을 추가한다. 글자·체력·채굴 진행은 512 × 192 CanvasTexture에 그리고 MeshBasicMaterial에 연결한다. 카메라 자식이 아니므로 실제 원근 투영을 받는다. 위치는 매 프레임 대상에서 읽고, 평면 회전은 카메라를 향하게 맞춘다. 블록은 조준한 0.5m 셀의 표면 중심에 고정된다.

대상과 주변 상호작용용으로 최대 두 장을 재사용한다. 텍스트와 수치가 바뀔 때만 텍스처를 갱신하며, 매 프레임 새 DOM·텍스처를 만들지 않는다. 렌더 그룹 순서를 1000으로 높이고 평면·연결선의 depthTest/depthWrite를 끈다. 지형 시선 검사로 창을 숨기지 않아 선택된 정보가 지형·반투명 물체에 가리지 않는다. 원근 투영과 렌더 우선순위는 독립적이며 정보창에는 안개를 적용하지 않는다. 연결선 다음에 평면을 그린다. 조준 대상 선정과 공격 사거리·지형 충돌 판정은 기존 규칙을 따른다. 시야 밖·거리 밖·너무 가까운 대상과 죽은 개체는 숨긴다. 최대 거리 직전 1.5m에서 흐려지며, 같은 거리에서도 화면 크기를 강제로 유지하지 않는다.

| 대상 | 표시 | 연결 |
| --- | --- | --- |
| 조준 생명체 | 이름·부위·체력·행동·사망 조건 | 살아 있는 엔티티 위치를 추적, 타격 시 체력 갱신 |
| 조준 블록 | 이름·도구·채굴 진행·사용 안내 | 선택 셀 표면에 고정, 채굴·대상 변경에 맞춰 갱신 |
| 가까운 수호자 | 이름·체력·충격파 예고 | 기존 보스의 상태·위치에 연결 |
| 가까운 마을 | 마을·집단·평판·교역 안내 | 마을 깃발 위치에 배치, 사용/R 또는 상호작용으로 대화 |

월드 정보 평면 자체는 터치 버튼이 아니다. 모바일은 기존 사용 버튼, 키보드는 R로 상호작용한다. 전투·이동 중 화면을 덮는 클릭 영역을 만들지 않는다. 인벤토리·설정·캐릭터 상태는 일시정지 후 여는 2D 게임 창이다. 캐릭터 상태는 장착 장비, 체력·포만·경험치, 같은 인벤토리의 식량·회복약을 보여준다. 내부 기록·설정만 스크롤하고 닫기·메뉴 프레임은 고정된다.

브라우저 검사 `tests/world-ui-check.cjs`에서 실제 대상 조준, 거리별 투영 크기, 엔티티 이동, 불투명·반투명 전경 위의 실제 픽셀 표시, 피해·사망, 터치 채굴, 마을 안내·대화, 세 가지 화면 크기, 회복약 소모와 가방 전환을 확인한다. 결과와 화면은 `verification/0.7.1/world-ui-results.json` 및 같은 폴더의 PNG.
