# 개인 마나 성장과 외부 액체 저장

상태: 실행 가능한 수치 제안. 원안의 “아이템을 통해 아바타 자신의 마나통을 키운다”를 기존 재료·장구로 구현한다. 아래 성장 수치는 원래 재료 카탈로그의 숨은 설정이 아니며 플레이 검증 후 조정할 수 있다.

## 개념과 분류

아바타의 내재 마나, 수피컵 안의 액체 마나, 고정 설비의 마나는 서로 다른 저장소다. `Progression.energy.magic`은 실물 설비 모드에서 아바타에게 실제 사용 가능한 마나만 나타낸다. 공격과 물성 부여는 이 값을 소비한다. 컵이나 근처 마나 탱크의 에너지를 합산하지 않는다.

내재 용량은 재료 투자로 영구 증가하고, 소유한 장구 한 개를 마나 초점으로 명시 장착하면 추가 용량을 얻는다. 재료는 소비되므로 같은 재료를 재사용할 수 없다. 초점은 하나의 슬롯에 하나만 지정하고, 장구 아이템의 실제 소유를 확인한다. 기존 장구의 전투 수치와 제작법은 바꾸지 않는다.

## 구성 관계와 수치

| 경로 | 요구 조건과 비용 | 용량 증가 | 상한 |
|---|---|---|---|
| 내재 마나 투자 | `mana` 연구, 5티어 이상 및 `manaCoupling >= 0.6`인 기존 재료를 1~10L 실제 소비 | `floor(20 × 재료 tier × manaCoupling) × L` | 투자로 700 EU |
| 장구 초점 | 소유한 `gear_baseline_t5`~`t10` 중 하나를 명시 장착 | `50 × (tier - 4)` EU | 한 슬롯, 50~300 EU |
| 아바타 전체 | 투자 용량 + 현재 소유한 초점의 용량 | 위 두 경로 합계 | 1000 EU |
| 수피컵 | 실제 `bark_cup` 소유 및 용기 선택 | 아바타 용량 증가 없음 | 액체 1L = 100 EU |
| 고정 액체 용기 | 실제 설치·배관 및 선택한 액체 | 아바타 용량 증가 없음 | 원래 용량 10L |

예: 마나 강철은 tier 5, manaCoupling 0.65이므로 1L 투자에 내재 용량 65 EU를 얻는다. 5티어 장구를 초점으로 지정하면 총 115 EU다. 이 두 행동 직후 마나는 **0 EU**다. 가방의 마나 액체 0.5L를 흡수하면 50 EU만 채워진다. 투자 상한에 가까울 때 실제 증가량은 남은 상한까지만이며, UI 견적이 이 실제 증가량을 보여준다.

## 동작 규칙

- 투자, 액체 흡수, 컵 충전·흡수는 각각 영속 `claimId`로 멱등 처리한다. 실패하면 재료나 에너지를 차감하지 않는다.
- 성장·장착은 에너지를 생성하지 않는다. `liquid_mana`는 기존 계약대로 1L당 100 EU만 공급한다.
- 초점을 해제하거나 사망·거래 등으로 아이템 소유를 잃어 용량이 줄면 초과 마나는 `reserveEU`에 보존한다. 사용할 수 있는 마나가 줄어도 보존분이 자동 보충되지는 않는다. **용량이 다시 증가할 때만 그 증가량 이내의 기존 잔액을 복원한다.**
- 따라서 장착·해제를 반복하거나 동일 아이템을 사망 지점에서 회수해도 새 마나는 생기지 않는다. 사망 회수의 아이템 이전은 기존 회수 원장을 사용한다. 마나 상태는 아바타 저장에 한 번만 존재한다.
- 컵의 `cupEU`는 별도 외부 저장이다. 컵이 가방에 없으면 접근할 수 없다. 컵을 선택·회수해도 액체를 새로 지급하지 않는다. 컵에서 아바타로 옮길 때 아바타 용량을 검사하고 컵의 잔량을 같은 양만큼 줄인다.
- 고정 용기에서 아바타로 이동하려면 현장 `FixtureEnergy.drain`을 명시 실행한다. 직접 연결하지 않은 설비나 다른 거점의 마나에 접근할 수 없다.
- 예전 프로토타입의 수피컵과 개인 마나가 합쳐진 저장은 컵의 기존 잔액으로 이전한다. 그 잔액을 새 내재 용량으로 간주하지 않는다.

## 변수 사전과 코드 연결

| 변수 | 위치/상태 | 타입·단위·범위 | 근거 및 검증 |
|---|---|---|---|
| `PERSONAL_MANA_RULES` | `content-runtime/progression.js`, 신규 실행 제안 | 불변 설정 | 재료·초점 비용을 공개 계산식으로 정의 |
| `personalMana.investedCapacity` | progression 저장 | number, EU, 0~700 | 저장된 `investments`의 재료별 공식 합계와 일치 검사 |
| `personalMana.investments` | progression 저장 | `{materialId: integer L}` | 카탈로그 tier·manaCoupling 자격 검사, 입력 실제 소비 |
| `personalMana.focusId` | progression 저장 | 장구 ID 또는 null | 5~10T 장구 중 한 개, 실제 가방 수량 검사 |
| `personalMana.reserveEU` | progression 저장 | number, 비음수 EU | 용량 감소분 보존, 소비로 인한 빈 공간에는 자동 보충 금지 |
| `personalMana.lastCapacity` | progression 저장 | number, 0~1000 EU | 실제 용량 증가분만큼만 보존 마나 복원 |
| `personalMana.cupEU` | progression 저장 | number, 0~100 EU | 실제 액체 소비/이체로만 변화 |
| `energy.magic` | 기존 progression 값의 실물모드 의미 명확화 | number, 0~현재 아바타 용량 | 고정망·컵 저장을 포함하지 않음 |

공개 API는 `quoteManaInvestment`, `investMana`, `equipManaFocus`, `unequipManaFocus`, `manaStatus`, `useManaCup`, `fillManaCup`, `absorbManaCup`, `fillPersonalMana`다. 화면은 `fixture-energy-panel.js`의 “아바타의 마나 성장”과 “휴대 에너지”에서 조작한다.

`tests/content-personal-mana.test.js`는 실제 재료 소비·상한·멱등성·저장 복원, 해제 후 소비 시 보존분을 우회 사용하는 문제, 사망 형태의 가방 제거/회수, 같은 장구 반복 장착, 컵과 내재 마나의 분리를 검사한다. 무위치 구형 모델의 기존 에너지 수치는 변경하지 않는다.
