# HP와 기관 손상: 2026-10-17 사용자 수정 반영

확정 원칙: 생물·보스 사망 기준은 전체 HP다. 외피 유효 타격도 정의된 에너지 방어 반응을 거쳐 전체 HP를 줄인다. 기관·뼈대 파손은 이동, 비행, 공격 기술 등 행동을 바꾸며 core 파손 자체가 HP를 0으로 만들지 않는다. 기존 보스 shell EU 값은 외피 파손 원장으로 유지하지만 전체 HP를 무효화하는 선행 소모 조건으로 쓰지 않는다.

실행 계약은 `RuntimePhysics.traceCombat({from,to,ownerId,mode,energyEU,amount})`다. 실제 인스턴스의 visible part matrixWorld와 개별 cuboid를 역변환한 선분으로 교차한다. 회전된 부위, 두께, 틈, 깊이 순서를 보존한다. 다른 owner의 실제 Rapier 고체가 앞을 막으면 전체 공격이 실패한다. 같은 owner의 겹치는 제작 cuboid는 중복 흡수하지 않는다. 내부의 작은 cuboid가 큰 외피 cuboid와 겹치면 내부 cuboid를 그 구간의 재질로 사용한다. 모델에 없는 뼈대를 만들어 맞았다고 가정하지 않는다.

반환 `effectiveAmount`는 전체 HP에 한 번 적용하는 방어 전 예산이다. `hits`/`structuralHits`는 같은 공격 예산의 기관별 분배이며 `amount`와 `energyEU` 합은 각각 입력값을 초과하지 않는다. 이를 별도 추가 HP 피해로 적용하면 안 된다. 부위 피해는 HP와 독립된 상태 변화이지만 HP 피해를 복제하는 공격은 아니다. 외피 침착 에너지도 유효한 HP 피해다. EU는 공격 진입 시 호출자가 한 번 소비하며 trace 함수는 인벤토리/에너지 원장을 변경하지 않는다.

현재 실행한 초기 제안 수치는 다음과 같다. 모두 현실 단위 환산이 없는 게임 EU 기준이며 밸런스 측정으로 확정한 값은 아니다.

| 변수 / 코드 | 값 | 근거와 검증 |
|---|---:|---|
| `COMBAT_TRACE_RULES.pierceDepthM` | 첫 피격면 뒤 1.2 m | 가까운 내부기관을 노릴 수 있게 한 시제품 상한; 전체 공격 사거리와 별개 |
| `impactDepthM` | 0.6 m | 관통보다 얕은 충격 전달; 빈 공간을 넘는 실제 교차기관만 대상 |
| `impactTransmission` | 0.65 | 재질 통과 뒤 남은 예산 중 깊은 기관에 전달되는 비율; 나머지는 외피에 침착 |
| 재질 `penetrationResistanceEUPerM` | 명시 시 해당 양의 유한값 | 자산별 정식 물성 입력 슬롯 |
| 위 값이 없는 연조직/목재/광물·골격/금속 | 24 / 60 / 120 / 180 EU/m | 기존 아트 자산에 관통 저항 정본이 없어 사용한 명시적 제안 fallback; material id 계열에 따른 분류 |

일반 타격은 첫 표면에 예산을 침착한다. 찌르기는 깊이 순서로 `관통 두께 × 재질 저항`을 침착시키고 잔여 예산이 있으면 다음 실제 기관에 도달한다. 충격 전달은 같은 재질 검사 후 깊은 기관과 첫 표면 사이에 잔여 예산을 나눈다. 따라서 단단하고 두꺼운 외피가 내부 기관을 보호해도 전체 HP가 무적이 되지는 않는다.

검증: `tests/combat-trace.test.js`는 표면/깊은기관/금속저항/최대깊이/회전 형상/실제 Rapier 외부 차폐와 틈을 확인한다. `tests/content-bosses.test.js`는 외피 HP 누적·core 파손 후 생존·공격 예산 중복 거절·24페이즈와 32기술을 확인한다. 변경 전 외피의 전량흡수가 전체 HP 피해를 0으로 만들던 테스트는 사용자 수정에 맞춰 교체했다.

## 기존 일반 모드 호환

`entities.js`의 외피 `damageHit`도 유효 타격마다 전체 HP를 한 번 차감한다. 기존 외피 마스크와 skeleton 저장 스키마를 유지한다. `think`의 `lost & 3`, `detach`의 core/head, `reconcileStructure`의 `state.alive`를 즉사 조건으로 쓰지 않는다. 공유 `structural-body.evaluateStructure` 계약은 그대로 두고 생명체 브리지에서만 사망을 전체 HP로 판단한다. 중앙 root 파손으로 연결 집합이 비더라도 살아 있는 외형의 전 부위를 자동 분리하지 않는다.

기존 골격 직접 타격의 `brain ×1.5`, 다른 골격 `×0.35` HP 계수는 호환을 위해 유지한다. 이미 노출된 뼈대에 대한 기관 손상과 이 HP 피해는 같은 타격의 두 결과이며 HP를 다시 차감하지 않는다. 일반 표면 타격은 입력 damage 한 번이다.

기존 창·활·곤봉·펄스 경로는 `damageHit(hit,time,radius,damage,{attackMode})`를 사용한다. 찌르기는 실제 조준 선분과 현재 내부 bone cuboid의 교차를 찾고, 충격은 피격점에서 가까운 내부 bone을 찾는다. 깊이 상한은 각각 1.2 m/0.6 m다. 기존 물리 충돌의 100 energy/HP 및 연조직 장벽 550 energy를 재사용하고, 무기 전달에 거리당 300 energy/m를 초기 제안으로 추가했다. 이는 legacy 충돌 에너지 스케일이며 expedition 게임 EU와 동일 단위라고 주장하지 않는다. 전달 에너지는 `max(0,damage×100−550−depth×300)`이고, 그 비율만 내부 골격에 적용한다. 전체 HP는 입력 damage를 한 번만 차감한다. 기존 물리 `impact` 역시 외피/내부 손상과 별개로 `min(80,energy/100)`의 단일 HP 예산을 적용한다.

`tests/legacy-combat.test.js`는 일반 외피만으로 처치, HP 저장, 중앙·뇌 파손 후 생존, 외피를 먼저 모두 제거하지 않는 한 번의 찌르기, 충격의 단일 HP/에너지 예산을 확인한다. 기존 골격 모양만 검증하던 테스트는 작은 HP 피해를 사용하도록 바꾸고, 외피 무피해·중추 즉사 기대는 최신 사용자 규칙으로 교체했다.
