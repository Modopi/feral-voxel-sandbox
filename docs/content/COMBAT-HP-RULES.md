# 전체 HP와 신체 파손의 역할

상태: 사용자 최신 확정 사항을 구현 중. 기존 문서의 핵심 골격 파괴 필수 조건보다 이 규칙이 우선한다.

## 확정된 규칙

- 생명체와 보스는 전체 HP가 0이 되면 사망한다. 외피를 전부 제거하고 깊은 골격을 정밀 조준해야만 처치할 수 있는 조건을 두지 않는다.
- 외피에 들어간 유효 공격도 재질·방어·속성을 반영해 전체 HP에 피해를 준다. 외피 내구도와 전체 HP는 서로 다른 상태로 유지한다.
- 골격과 기관의 손상은 이동, 자세, 비행, 조작, 공격 기술 등 행동을 바꾼다. 핵심 골격의 파손만으로 남은 전체 HP를 강제로 0으로 바꾸지 않는다.
- 하나의 공격이 여러 부위에 닿더라도 전체 HP 피해를 부위 수만큼 반복하지 않는다. 내부 부위 손상은 같은 공격의 유한한 피해·에너지 예산에서 나눠 적용한다.
- 외피 뒤에 있는 부위를 한 번의 공격으로 손상시킬 수단을 제공한다. 관통 공격은 실제 경로와 재질 저항을, 충격 전달은 접촉 지점부터의 내부 전달 범위를 판정한다.
- 다른 객체나 지형이 앞을 가리면 해당 차폐를 먼저 처리한다. 같은 생명체 내부의 파손 판정과 서로 다른 객체의 충돌 규칙을 혼동하지 않는다.
- 분리된 부위는 사물 엔티티가 되며, 원래 개체와 파편의 질량 합계 및 단일 전리품 원장을 유지한다.

## 첫 구현의 조작·수치 제안

일반 타격, 관통 찌르기, 충격 전달을 선택할 수 있도록 연결한다. 기존 무기·에너지의 전체 피해량과 소모 비용을 공통 예산으로 사용하고, 공격 방식에 따라 표면과 내부의 배분만 달라진다. 무기마다 별도 장구 설계를 마쳤다는 의미는 아니다.

첫 물리 판정안은 첫 접촉면 이후 관통 최대 1.2m, 충격 전달 최대 0.6m다. 실제 도달 깊이는 교차한 복셀의 재질 저항과 남은 에너지로 줄어든다. 이 거리와 배분 계수는 플레이 검증 전 밸런스 제안이며, 사용자 확정 수치로 표현하지 않는다.

기존 탐험 모드에도 같은 HP·파손 원칙을 적용한다. 기존 창·활·수정궁은 관통, 곤봉·충격파 도구는 충격 전달을 사용한다. 무기 이름 옆과 제작 설명에서 공격 방식을 확인할 수 있다. 신규 콘텐츠 탐험은 일반 타격·관통 찌르기·충격 전달 선택 버튼을 제공한다. 두 모드의 기존 신체 해상도와 재질 체계가 다르므로 내부 전달 저항의 단위·환산은 [COMBAT-TRACE-PROPOSAL.md](COMBAT-TRACE-PROPOSAL.md)에 따로 기록한다.

## 필요한 검증

1. 외피만 계속 타격해도 전체 HP가 소진되어 처치할 수 있다.
2. 전체 HP가 남은 개체의 골격이 파손되면 해당 행동이 변하고, 사망하거나 전체 형상이 사라지지 않는다.
3. 관통과 충격은 실제로 내부 부위에 도달하며, 차폐·깊이·재질 저항에 막힐 수 있다.
4. 여러 외피/기관을 지난 공격의 총 피해·소모 에너지는 원래 한 번의 예산을 넘지 않는다.
5. 화면상의 타격 부위, 실제 충돌 형상, HP·파손 결과, 저장 후 복원 결과가 일치한다.

구현과 검증 근거는 [IMPLEMENTATION-STATUS.md](IMPLEMENTATION-STATUS.md)에 기록한다.
