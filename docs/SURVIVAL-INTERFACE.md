# 0.5.0 완료 기준과 플레이 구조

이번 버전의 목표는 사용자가 지정한 세 가지다. 마인크래프트를 참고한 기본 인벤토리 인터페이스, 기본적인 생태 구조, 모바일 조작에 맞는 통합이다. 게임 전체를 마인크래프트와 동등하게 만들었다는 의미는 아니다. 그래픽은 직접 작성한 SVG/복셀 형상을 사용한다.

| 완료 기준 | 구현 | 검증 |
|---|---|---|
| 실제 아이템을 다루는 하단 툴바 | 보관함과 같은 데이터의 9칸 핫바, 수량·내구도·선택 테두리, 복셀 아이콘과 손에 든 형상 | 터치 슬롯 선택 → 장착 → 채굴/설치, 재접속 보존 |
| 기본 인벤토리 창 | 27칸 보관함 + 9칸 핫바, 플레이어 프리뷰, 제작법·2×2 재료 미리보기·결과 슬롯 | 제작 → 슬롯 이동 → 나누기 → 합치기, 빈 칸 검증 |

## 아이템과 슬롯

슬롯 0~8이 핫바, 9~35가 보관함이다. 클릭/탭으로 출발 칸과 목적지를 선택하거나 끌어서 이동한다. 같은 물품끼리는 최대 64개까지 합치고, 다른 물품이면 교환한다. `나누기`를 켜면 절반(홀수는 올림)을 옮긴다. 출발 칸을 선택만 한 상태에서는 아이템을 제거하지 않으므로 메뉴 닫기·입력 취소로 유실되지 않는다.

제작법을 선택하면 필요한 재료와 보유 수량이 2×2 미리보기에 나타난다. 결과 슬롯을 누르면 재료를 소비하고 실제 빈 슬롯에 결과를 넣는다. 재료와 결과 공간을 함께 검사하며 실패하면 소지품을 변경하지 않는다. 수동 조합식 배치는 구현하지 않았고 제작법을 선택하는 방식이다. 도구는 보유한 개별 슬롯으로 선택하고 내구도 0이면 수리 전까지 사용할 수 없다. 수리는 제작 재료의 절반(종류별 올림)을 사용한다.

블록 조각은 0.5m 셀 단위다. 설치 범위 0.5m는 1개, 1m는 8개를 소비한다. `놓기 ×1/×8`으로 표시한다. 플레이어와 겹치는 설치는 거부한다. 채굴한 자원은 근처에서 자동 수집하지만 가방이 가득 차면 바닥에 남는다.

구 저장의 재료·해금 장비를 슬롯으로 이전한다. 용량을 넘는 이전 물품과 보상은 `보관품 받기`에서 빈 칸만큼 되찾을 수 있다. 이는 새로운 무제한 사용 가방이 아니며 보관함으로 들어온 뒤에만 사용할 수 있다. 신형 저장은 슬롯 배치·선택 칸·내구도·남은 보관품을 유지한다.

## 생태와 생존

초식동물은 풀을 먹고 포식자를 피한다. 씨앗을 손에 든 플레이어를 7m 안에서 따라오며 3m 안에서 `먹이·심기`로 씨앗 1개를 줄 수 있다. 5m 안의 같은 종 성체 두 마리가 먹이를 받으면 자손 한 마리가 태어난다. 성장까지 25초, 부모 번식 휴식은 90초다. 자연 번식도 성체 짝과 충분한 영양이 있어야 한다.

구리여우는 낮에는 동물을 사냥하며 공격받으면 플레이어에게 반격한다. 19시~6시는 야간 사냥으로 가까운 플레이어를 추적한다. 물리적 거리가 가깝고 지형에 가리지 않을 때만 피해를 주며 공격 간격은 1초다. 시간 표시와 하늘 밝기는 같은 낮/밤 주기를 사용한다. 개척 원정에서 플레이어 체력·포만·회복과 연결된다. 기본 섬은 기존 생태 실험 모드를 유지한다.

사냥한 사슴/여우는 날고기를 떨어뜨린다. 날고기와 목재로 구운 식량을 만들어 개척 원정의 포만을 회복한다. 식생 복원·채집·초식·포식·토양 환원은 기존 월드 시뮬레이션에 연결된다.

## 조작

- 모바일: 스틱 이동(끝까지 밀면 달리기), 빈 화면 드래그로 시점, `공격·캐기` 길게 누르기, `사용`으로 블록 설치·먹이·식량·마을 상호작용. 손을 떼거나 터치가 취소되면 즉시 해제한다.
- 키보드/마우스: WASD·Shift·Space, 1~9/휠 아이템 선택, 좌클릭 공격/채굴, 우클릭 사용/설치, I/Tab 가방, B 범위, Esc 메뉴.
- 대상 정보는 좌/우 사이드 표시다. 중앙 모달은 가방·메뉴를 명시적으로 열었을 때만 표시한다.
