# 움직이는 복셀 기계 — Vertical Slice 0.1

제품 빌드 0.3.0의 실험 기능. 기존 탐험과 별도 시험장·저장 공간 사용.

## 책임과 데이터 계약

| 영역        | 소유 데이터                           | 입력 → 결과                              |
| ----------- | ------------------------------------- | ---------------------------------------- |
| 설계도      | 안정적인 부품 ID, 종류, 격자 좌표     | 조립/제거 → 새 구성                      |
| 런타임 상태 | 부품별 HP, 위치·속도·방향, 시간·자원  | 명령 → 상태 변화                         |
| 기능 평가   | 원점 차체와 6면 연결된 살아 있는 부품 | 구성+HP → 질량·출력·접지·조향            |
| 역학        | 고정 60Hz, 평면 차량 운동             | 추상 throttle/steer/brake → 힘·가속·충돌 |
| 표현·입력   | Three.js 메시, 편집 격자, 터치·키보드 | 입력 → 명령 / 상태 → 화면                |

`model.js`는 DOM·Three.js·기기 입력을 참조하지 않는다. 렌더러는 상태를 읽고 명령만 제출한다. 설계도는 손상으로 변경하지 않으며 HP 0 부품도 교체할 자리로 남는다. 연결이 끊긴 부품은 질량에는 포함되고 기능은 정지한다. 원점 차체는 조립 기준점이며 파괴되면 전체 기능 정지. 장식 복셀도 질량에 반영한다.

## 사례

- 전진: 스틱/키 → throttle → 연결 모터 출력×HP → 바퀴 접지×HP → 힘/질량 → 속도·위치 → 렌더.
- 충돌: 고정 장애물과 보수적인 차량 원 충돌 → 법선 속도 차단 → 가장 가까운 살아 있는 복셀 HP 감소 → 다음 틱 기능 재평가.
- 수리/교체: 정지한 조립 모드 → 자원 검증 → HP 복구/부품 제거·재배치 → 연결성·동작 재평가.
- 자원: 광맥 근처 정지 → 채굴 명령 → 유한 광맥 감소·재료 증가 → 조립 소비.

## 검증 범위

동일 제어 명령으로 경량/중량 설계 가속도 비교, 모터·바퀴 파손 전후 주행 비교, 수리 복원, 분리된 기능 정지, 충돌·경계, 원자적 자원 소비, 설계도와 상태 저장 왕복. 모바일 화면에서 실제 버튼과 격자 조작 검증.

수평 고정 지면의 간이 역학이다. 바퀴 접지·좌우 균형을 집계하고 모터 힘·항력·브레이크를 계산한다. 3D 강체·서스펜션·관절·전복·구조물 분리는 후속 범위. 무장·NPC·무한 월드·경제 제외. 시험장은 기존 섬의 자원을 공유하지 않는다.
