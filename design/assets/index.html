세계를 이루는
형태의 원본.

환경, 생명체, 건축물과 보스를 같은 복셀 자산 체계로 모았습니다. 이미지를 누르면 실제 원본을 회전해 볼 수 있습니다. 지붕을 숨겨 내부 구조를 확인하고, JSON 또는 GLB로 디자인을 가져가세요.

시각 원형 · 아래 이미지는 복셀 원본에서 직접 렌더했습니다. 게임 적용, 최종 애니메이션·충돌체·재질 셰이더는 아직 포함하지 않습니다. 별도 콘셉트 이미지는 형태·색감 참고 자료입니다.
